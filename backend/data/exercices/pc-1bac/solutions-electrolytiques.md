### Exercice 1 : Équations de dissolution
\begin{enonce}
Écrire l'équation de dissolution dans l'eau de chacun des solides ioniques suivants, en précisant les états physiques :
\begin{enumerate}
    \item le chlorure de potassium $\text{KCl}$ ;
    \item le chlorure de calcium $\text{CaCl}_2$ ;
    \item le sulfate de sodium $\text{Na}_2\text{SO}_4$ ;
    \item le nitrate de fer (III) $\text{Fe(NO}_3)_3$.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
Chaque équation doit respecter la conservation des éléments et la conservation de la charge (la solution obtenue est globalement neutre).
\begin{enumerate}
    \item $\text{KCl}_{(s)} \longrightarrow \text{K}^+_{(aq)} + \text{Cl}^-_{(aq)}$
    \item $\text{CaCl}_{2\,(s)} \longrightarrow \text{Ca}^{2+}_{(aq)} + 2\,\text{Cl}^-_{(aq)}$
    \item $\text{Na}_2\text{SO}_{4\,(s)} \longrightarrow 2\,\text{Na}^+_{(aq)} + \text{SO}_4^{2-}{}_{(aq)}$
    \item $\text{Fe(NO}_3)_{3\,(s)} \longrightarrow \text{Fe}^{3+}_{(aq)} + 3\,\text{NO}_3^-{}_{(aq)}$
\end{enumerate}
On vérifie à chaque fois la neutralité : par exemple pour $\text{CaCl}_2$, une charge $+2$ compensée par $2 \times (-1)$, soit une charge totale nulle.

### Exercice 2 : Concentration molaire apportée
\begin{enonce}
On dissout $m = 5{,}85\ \text{g}$ de chlorure de sodium $\text{NaCl}$ dans de l'eau pour obtenir $V = 250\ \text{mL}$ de solution.
Donnée : masse molaire $M(\text{NaCl}) = 58{,}5\ \text{g}\cdot\text{mol}^{-1}$.
\begin{enumerate}
    \item Calculer la quantité de matière $n$ de $\text{NaCl}$ dissous.
    \item En déduire la concentration molaire apportée $C$ de la solution.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item La quantité de matière vaut :
$$n = \dfrac{m}{M} = \dfrac{5{,}85}{58{,}5} = 0{,}100\ \text{mol}$$
    \item Avec $V = 250\ \text{mL} = 0{,}250\ \text{L}$ :
$$C = \dfrac{n}{V} = \dfrac{0{,}100}{0{,}250} = 0{,}400\ \text{mol}\cdot\text{L}^{-1}$$
\end{enumerate}

### Exercice 3 : Concentrations effectives des ions
\begin{enonce}
On prépare une solution de chlorure de fer (III) $\text{FeCl}_3$ de concentration apportée $C = 0{,}20\ \text{mol}\cdot\text{L}^{-1}$. La dissolution est totale.
\begin{enumerate}
    \item Écrire l'équation de dissolution de $\text{FeCl}_3$.
    \item Exprimer puis calculer les concentrations effectives $[\text{Fe}^{3+}]$ et $[\text{Cl}^-]$.
    \item Vérifier la relation d'électroneutralité de la solution.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item $\text{FeCl}_{3\,(s)} \longrightarrow \text{Fe}^{3+}_{(aq)} + 3\,\text{Cl}^-_{(aq)}$
    \item Une mole de $\text{FeCl}_3$ libère une mole de $\text{Fe}^{3+}$ et trois moles de $\text{Cl}^-$ :
$$[\text{Fe}^{3+}] = C = 0{,}20\ \text{mol}\cdot\text{L}^{-1}$$
$$[\text{Cl}^-] = 3\,C = 3 \times 0{,}20 = 0{,}60\ \text{mol}\cdot\text{L}^{-1}$$
    \item L'électroneutralité s'écrit $3\,[\text{Fe}^{3+}] = [\text{Cl}^-]$ (charges positives = charges négatives) :
$$3 \times 0{,}20 = 0{,}60 = [\text{Cl}^-]\ \checkmark$$
La solution est bien électriquement neutre.
\end{enumerate}

### Exercice 4 : Dilution d'une solution
\begin{enonce}
On dispose d'une solution mère de glucose de concentration $C_1 = 0{,}50\ \text{mol}\cdot\text{L}^{-1}$. On souhaite préparer $V_2 = 200\ \text{mL}$ d'une solution fille de concentration $C_2 = 0{,}10\ \text{mol}\cdot\text{L}^{-1}$.
\begin{enumerate}
    \item Quel volume $V_1$ de solution mère faut-il prélever ?
    \item Quel est le facteur de dilution ?
    \item Décrire brièvement le protocole et la verrerie utilisée.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item La relation de dilution $C_1 V_1 = C_2 V_2$ donne :
$$V_1 = \dfrac{C_2\,V_2}{C_1} = \dfrac{0{,}10 \times 200}{0{,}50} = 40\ \text{mL}$$
    \item Le facteur de dilution vaut :
$$F = \dfrac{C_1}{C_2} = \dfrac{0{,}50}{0{,}10} = 5$$
La solution est diluée 5 fois.
    \item On prélève $40\ \text{mL}$ de solution mère à la pipette jaugée, on les verse dans une fiole jaugée de $200\ \text{mL}$, puis on complète avec de l'eau distillée jusqu'au trait de jauge et on homogénéise.
\end{enumerate}

### Exercice 5 : Mélange et électroneutralité
\begin{enonce}
On dissout du nitrate de potassium $\text{KNO}_3$ et du nitrate de calcium $\text{Ca(NO}_3)_2$ dans le même volume d'eau. Les concentrations apportées sont $C_1 = 0{,}10\ \text{mol}\cdot\text{L}^{-1}$ pour $\text{KNO}_3$ et $C_2 = 0{,}050\ \text{mol}\cdot\text{L}^{-1}$ pour $\text{Ca(NO}_3)_2$.
\begin{enumerate}
    \item Écrire les deux équations de dissolution.
    \item Calculer les concentrations effectives $[\text{K}^+]$, $[\text{Ca}^{2+}]$ et $[\text{NO}_3^-]$.
    \item Vérifier l'électroneutralité de la solution finale.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Les équations de dissolution sont :
$$\text{KNO}_{3\,(s)} \longrightarrow \text{K}^+_{(aq)} + \text{NO}_3^-{}_{(aq)}$$
$$\text{Ca(NO}_3)_{2\,(s)} \longrightarrow \text{Ca}^{2+}_{(aq)} + 2\,\text{NO}_3^-{}_{(aq)}$$
    \item Les cations proviennent chacun d'un seul soluté :
$$[\text{K}^+] = C_1 = 0{,}10\ \text{mol}\cdot\text{L}^{-1}, \qquad [\text{Ca}^{2+}] = C_2 = 0{,}050\ \text{mol}\cdot\text{L}^{-1}$$
Les ions $\text{NO}_3^-$ proviennent des deux solutés :
$$[\text{NO}_3^-] = C_1 + 2\,C_2 = 0{,}10 + 2 \times 0{,}050 = 0{,}20\ \text{mol}\cdot\text{L}^{-1}$$
    \item L'électroneutralité impose $[\text{K}^+] + 2\,[\text{Ca}^{2+}] = [\text{NO}_3^-]$ :
$$0{,}10 + 2 \times 0{,}050 = 0{,}20 = [\text{NO}_3^-]\ \checkmark$$
\end{enumerate}

### Exercice 6 : Du solide à la solution diluée
\begin{enonce}
On veut préparer $V = 500\ \text{mL}$ d'une solution de sulfate de cuivre (II) $\text{CuSO}_4$ de concentration apportée $C = 0{,}10\ \text{mol}\cdot\text{L}^{-1}$.
Donnée : $M(\text{CuSO}_4) = 159{,}5\ \text{g}\cdot\text{mol}^{-1}$.
\begin{enumerate}
    \item Calculer la masse $m$ de $\text{CuSO}_4$ à peser.
    \item Donner les concentrations effectives $[\text{Cu}^{2+}]$ et $[\text{SO}_4^{2-}]$.
    \item On prélève ensuite $V_1 = 50\ \text{mL}$ de cette solution que l'on complète à $V_2 = 250\ \text{mL}$. Calculer la nouvelle concentration $C_2$.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item La quantité de matière nécessaire est $n = C \times V = 0{,}10 \times 0{,}500 = 0{,}050\ \text{mol}$. D'où :
$$m = n \times M = 0{,}050 \times 159{,}5 = 7{,}975 \approx 8{,}0\ \text{g}$$
    \item L'équation $\text{CuSO}_{4\,(s)} \longrightarrow \text{Cu}^{2+}_{(aq)} + \text{SO}_4^{2-}{}_{(aq)}$ donne, les coefficients valant 1 :
$$[\text{Cu}^{2+}] = [\text{SO}_4^{2-}] = C = 0{,}10\ \text{mol}\cdot\text{L}^{-1}$$
    \item La relation de dilution donne :
$$C_2 = \dfrac{C\,V_1}{V_2} = \dfrac{0{,}10 \times 50}{250} = 0{,}020\ \text{mol}\cdot\text{L}^{-1}$$
\end{enumerate}

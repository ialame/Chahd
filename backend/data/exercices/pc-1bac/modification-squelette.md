### Exercice 1 : Reconnaître le type de modification
\begin{enonce}
Pour chacune des transformations suivantes, indiquer s'il s'agit d'un **craquage**, d'un **vapocraquage**, d'un **reformage** ou d'une **polymérisation**. Justifier brièvement.
\begin{enumerate}
    \item $C_{12}H_{26} \longrightarrow C_8H_{18} + C_4H_8$
    \item $C_3H_8 \longrightarrow C_3H_6 + H_2$ (à $850\ ^{\circ}\text{C}$, en présence de vapeur d'eau)
    \item Hexane $C_6H_{14}$ (linéaire) $\longrightarrow$ 2-méthylpentane $C_6H_{14}$ (ramifié)
    \item $n\,(CH_2=CH_2) \longrightarrow {-\!\!\left(CH_2-CH_2\right)\!\!-}_{n}$
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item **Craquage** : la chaîne longue est rompue en une molécule plus courte ($C_8H_{18}$) et un alcène ($C_4H_8$). Le nombre de carbones diminue.
    \item **Vapocraquage** : transformation à haute température avec vapeur d'eau, qui produit un alcène ($C_3H_6$) et du dihydrogène.
    \item **Reformage** : le nombre d'atomes de carbone est conservé ($C_6H_{14}$ dans les deux cas) ; seule la **forme** du squelette change (linéaire $\to$ ramifié).
    \item **Polymérisation** (polyaddition) : un grand nombre de monomères à double liaison $C=C$ s'enchaînent pour former une macromolécule.
\end{enumerate}

### Exercice 2 : Équations de craquage
\begin{enonce}
Le craquage du tétradécane $C_{14}H_{30}$ peut donner différents couples de produits.
\begin{enumerate}
    \item Compléter l'équation : $C_{14}H_{30} \longrightarrow C_8H_{18} + \ldots$
    \item Compléter l'équation : $C_{14}H_{30} \longrightarrow C_5H_{12} + \ldots$
    \item Dans chaque cas, préciser quel produit est un **alcane** et lequel est un **alcène**.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item On conserve les atomes : carbone $14 - 8 = 6$, hydrogène $30 - 18 = 12$, donc le second produit est $C_6H_{12}$ :
\[
C_{14}H_{30} \longrightarrow C_8H_{18} + C_6H_{12}
\]
    \item Carbone $14 - 5 = 9$, hydrogène $30 - 12 = 18$, donc le second produit est $C_9H_{18}$ :
\[
C_{14}H_{30} \longrightarrow C_5H_{12} + C_9H_{18}
\]
    \item Dans les deux cas, le produit de formule $C_nH_{2n+2}$ ($C_8H_{18}$, puis $C_5H_{12}$) est un **alcane**, et celui de formule $C_nH_{2n}$ ($C_6H_{12}$, puis $C_9H_{18}$) est un **alcène**.
\end{enumerate}

### Exercice 3 : Vapocraquage de l'éthane
\begin{enonce}
Dans un vapocraqueur, l'éthane $C_2H_6$ est transformé vers $850\ ^{\circ}\text{C}$.
\begin{enumerate}
    \item Écrire l'équation de la formation de l'éthène $C_2H_4$ à partir de l'éthane.
    \item Quelle est l'autre molécule formée ?
    \item En quoi le vapocraquage diffère-t-il du craquage catalytique (température, catalyseur, produits visés) ?
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item La double liaison se forme par perte de deux atomes d'hydrogène :
\[
C_2H_6 \longrightarrow C_2H_4 + H_2
\]
    \item L'autre molécule formée est le **dihydrogène** $H_2$.
    \item Le craquage catalytique se fait vers $500\ ^{\circ}\text{C}$ **avec catalyseur** pour produire surtout des carburants ; le vapocraquage se fait à plus haute température ($800$–$900\ ^{\circ}\text{C}$), **sans catalyseur** mais avec vapeur d'eau, et vise surtout les **alcènes** (éthène, propène) destinés aux plastiques.
\end{enumerate}

### Exercice 4 : Reformage et isomérie
\begin{enonce}
Le reformage transforme l'hexane $C_6H_{14}$, alcane linéaire, en alcanes ramifiés de meilleur indice d'octane.
\begin{enumerate}
    \item Vérifier que le 2,2-diméthylbutane a la même formule brute que l'hexane.
    \item Comment appelle-t-on deux molécules de même formule brute mais de squelettes différents ?
    \item Le nombre d'atomes de carbone change-t-il au cours du reformage ? Quel intérêt présente la chaîne ramifiée pour un carburant ?
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Le 2,2-diméthylbutane possède une chaîne principale de 4 carbones portant deux groupes méthyle, soit $4 + 2 = 6$ carbones, et $14$ hydrogènes : sa formule brute est bien $C_6H_{14}$, identique à celle de l'hexane.
    \item Ce sont des **isomères** (ici des isomères de constitution, de chaîne).
    \item Le nombre d'atomes de carbone **ne change pas** ($C_6H_{14}$ dans les deux cas) : le reformage ne fait que modifier la forme du squelette. La chaîne ramifiée a un **meilleur indice d'octane**, donc une meilleure résistance à l'auto-allumage dans le moteur.
\end{enumerate}

### Exercice 5 : Polyaddition de l'éthène
\begin{enonce}
On réalise la polymérisation de l'éthène $CH_2=CH_2$ en polyéthène (polyéthylène, PE).
Données : $M(C) = 12\ \text{g/mol}$, $M(H) = 1\ \text{g/mol}$.
\begin{enumerate}
    \item Écrire l'équation de la polyaddition et identifier le **motif** du polymère.
    \item Calculer la masse molaire $M_{\text{motif}}$ du motif.
    \item Un échantillon de PE a une masse molaire $M_{\text{polymère}} = 70\ 000\ \text{g/mol}$. Calculer le degré de polymérisation $n$.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item La double liaison s'ouvre et les motifs s'enchaînent :
\[
n\,(CH_2=CH_2) \longrightarrow {-\!\!\left(CH_2-CH_2\right)\!\!-}_{n}
\]
Le **motif** (unité qui se répète) est $-CH_2-CH_2-$, de formule $C_2H_4$.
    \item $M_{\text{motif}} = 2 \times M(C) + 4 \times M(H) = 2 \times 12 + 4 \times 1 = 28\ \text{g/mol}$.
    \item Le degré de polymérisation vérifie $M_{\text{polymère}} = n \times M_{\text{motif}}$, donc :
\[
n = \frac{M_{\text{polymère}}}{M_{\text{motif}}} = \frac{70\ 000}{28} = 2500.
\]
Chaque macromolécule est formée d'environ $2500$ motifs.
\end{enumerate}

### Exercice 6 : Le poly(chlorure de vinyle)
\begin{enonce}
Le PVC est obtenu par polyaddition du chlorure de vinyle $CH_2=CHCl$.
Données : $M(C) = 12$, $M(H) = 1$, $M(Cl) = 35{,}5\ \text{g/mol}$.
\begin{enumerate}
    \item Écrire l'équation de la polymérisation et donner le motif du PVC.
    \item Calculer la masse molaire du motif.
    \item Une macromolécule de PVC contient $n = 1200$ motifs. Calculer sa masse molaire.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item La double liaison s'ouvre :
\[
n\,(CH_2=CHCl) \longrightarrow {-\!\!\left(CH_2-CHCl\right)\!\!-}_{n}
\]
Le motif est $-CH_2-CHCl-$, de formule $C_2H_3Cl$.
    \item $M_{\text{motif}} = 2 \times 12 + 3 \times 1 + 35{,}5 = 24 + 3 + 35{,}5 = 62{,}5\ \text{g/mol}$.
    \item $M_{\text{polymère}} = n \times M_{\text{motif}} = 1200 \times 62{,}5 = 75\ 000\ \text{g/mol}$.
\end{enumerate}

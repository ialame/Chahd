### Exercice 1 : Équation de la réaction d'estérification
\begin{enonce}
On fait réagir l'acide éthanoïque (acide acétique) $\text{CH}_3\text{COOH}$ avec l'éthanol $\text{C}_2\text{H}_5\text{OH}$.
\begin{enumerate}
    \item Écrire l'équation de la réaction d'estérification en précisant le nom et la formule de l'ester formé.
    \item Citer les trois caractères de cette réaction.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item La réaction entre un acide carboxylique et un alcool produit un ester et de l'eau :
    \[
    \text{CH}_3\text{COOH} + \text{C}_2\text{H}_5\text{OH} \rightleftharpoons \text{CH}_3\text{COOC}_2\text{H}_5 + \text{H}_2\text{O}
    \]
    L'ester formé est l'éthanoate d'éthyle (acétate d'éthyle), de formule $\text{CH}_3\text{COOC}_2\text{H}_5$.
    \item La réaction d'estérification est :
    \begin{itemize}
        \item \textbf{lente} (elle dure plusieurs heures à température ambiante) ;
        \item \textbf{limitée} (équilibrée) : elle n'est jamais totale car la réaction inverse d'hydrolyse se produit en même temps ;
        \item \textbf{athermique} : elle ne s'accompagne pratiquement d'aucun échange de chaleur ($\Delta T \approx 0$).
    \end{itemize}
\end{enumerate}

### Exercice 2 : Calcul de quantités de matière initiales
\begin{enonce}
On mélange une masse $m_1 = 6{,}0\ \text{g}$ d'acide éthanoïque $\text{CH}_3\text{COOH}$ avec une masse $m_2 = 4{,}6\ \text{g}$ d'éthanol $\text{C}_2\text{H}_5\text{OH}$.

Données : $M(\text{CH}_3\text{COOH}) = 60\ \text{g.mol}^{-1}$ ; $M(\text{C}_2\text{H}_5\text{OH}) = 46\ \text{g.mol}^{-1}$.

Déterminer les quantités de matière initiales d'acide et d'alcool. Le mélange est-il équimolaire ?
\end{enonce}

\textbf{Solution :}
La quantité de matière initiale d'acide :
\[
n_1 = \frac{m_1}{M(\text{CH}_3\text{COOH})} = \frac{6{,}0}{60} = 0{,}10\ \text{mol}
\]
La quantité de matière initiale d'alcool :
\[
n_2 = \frac{m_2}{M(\text{C}_2\text{H}_5\text{OH})} = \frac{4{,}6}{46} = 0{,}10\ \text{mol}
\]
Comme $n_1 = n_2 = 0{,}10\ \text{mol}$, le mélange est bien \textbf{équimolaire}.

### Exercice 3 : Tableau d'avancement et rendement
\begin{enonce}
On part du mélange équimolaire de l'exercice 2 : $n_1 = n_2 = 0{,}10\ \text{mol}$. À l'équilibre, on trouve qu'il s'est formé $n_{ester,f} = 0{,}067\ \text{mol}$ d'ester.
\begin{enumerate}
    \item Dresser le tableau d'avancement de la réaction.
    \item Déterminer l'avancement à l'équilibre $x_{eq}$.
    \item Calculer le rendement $r$ de la réaction.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Tableau d'avancement (en mol) :
    \[
    \begin{aligned}
    &\text{État initial :} && \text{acide : } 0{,}10 \quad \text{alcool : } 0{,}10 \quad \text{ester : } 0 \quad \text{eau : } 0 \\
    &\text{État interm. } (x) : && 0{,}10 - x \quad\quad\ \ 0{,}10 - x \quad\quad\ x \quad\quad\ \ x \\
    &\text{État final } (x_{eq}) : && 0{,}10 - x_{eq} \quad 0{,}10 - x_{eq} \quad x_{eq} \quad x_{eq}
    \end{aligned}
    \]
    \item L'ester apparaît avec l'avancement : $n_{ester,f} = x_{eq}$, donc :
    \[
    x_{eq} = 0{,}067\ \text{mol}
    \]
    \item Comme le mélange est équimolaire, les deux réactifs sont en proportions stœchiométriques : l'avancement maximal est $x_{max} = 0{,}10\ \text{mol}$ (si la réaction était totale, $n_{ester,max} = 0{,}10\ \text{mol}$). Le rendement :
    \[
    r = \frac{n_{ester,f}}{n_{ester,max}} = \frac{x_{eq}}{x_{max}} = \frac{0{,}067}{0{,}10} = 0{,}67 = 67\,\%
    \]
    Ce rendement d'environ $67\,\%$ est caractéristique d'un mélange équimolaire avec un alcool primaire.
\end{enumerate}

### Exercice 4 : Composition du mélange à l'équilibre
\begin{enonce}
On reprend le mélange équimolaire ($n_1 = n_2 = 0{,}10\ \text{mol}$) pour lequel $x_{eq} = 0{,}067\ \text{mol}$.

Déterminer la quantité de matière de chaque espèce présente dans le mélange à l'équilibre.
\end{enonce}

\textbf{Solution :}
À l'équilibre, on utilise les expressions du tableau d'avancement avec $x_{eq} = 0{,}067\ \text{mol}$ :
\[
\begin{aligned}
n_{acide} &= 0{,}10 - x_{eq} = 0{,}10 - 0{,}067 = 0{,}033\ \text{mol} \\
n_{alcool} &= 0{,}10 - x_{eq} = 0{,}033\ \text{mol} \\
n_{ester} &= x_{eq} = 0{,}067\ \text{mol} \\
n_{eau} &= x_{eq} = 0{,}067\ \text{mol}
\end{aligned}
\]
Il reste donc $0{,}033\ \text{mol}$ de chaque réactif et il s'est formé $0{,}067\ \text{mol}$ d'ester et d'eau.

### Exercice 5 : Réaction d'hydrolyse de l'ester
\begin{enonce}
On introduit $n_0 = 0{,}10\ \text{mol}$ d'éthanoate d'éthyle $\text{CH}_3\text{COOC}_2\text{H}_5$ avec $0{,}10\ \text{mol}$ d'eau.
\begin{enumerate}
    \item Écrire l'équation de la réaction d'hydrolyse de l'ester.
    \item À l'équilibre, on mesure $0{,}033\ \text{mol}$ d'acide formé. Calculer le rendement de cette hydrolyse.
    \item Comparer cet équilibre à celui de l'estérification du mélange équimolaire.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item L'hydrolyse est la réaction inverse de l'estérification : l'ester réagit avec l'eau pour redonner l'acide et l'alcool :
    \[
    \text{CH}_3\text{COOC}_2\text{H}_5 + \text{H}_2\text{O} \rightleftharpoons \text{CH}_3\text{COOH} + \text{C}_2\text{H}_5\text{OH}
    \]
    \item L'acide se forme avec l'avancement : $x_{eq} = n_{acide} = 0{,}033\ \text{mol}$. L'avancement maximal (réaction totale) serait $x_{max} = 0{,}10\ \text{mol}$, d'où :
    \[
    r = \frac{x_{eq}}{x_{max}} = \frac{0{,}033}{0{,}10} = 0{,}33 = 33\,\%
    \]
    \item On atteint le \textbf{même état d'équilibre} que par estérification : dans les deux cas le mélange final contient $0{,}067\ \text{mol}$ d'ester et $0{,}033\ \text{mol}$ d'acide. L'équilibre est indépendant du sens dans lequel on l'aborde.
\end{enumerate}

### Exercice 6 : Influence de l'excès d'un réactif
\begin{enonce}
On veut améliorer le rendement de la formation de l'éthanoate d'éthyle. On garde $n_1 = 0{,}10\ \text{mol}$ d'acide mais on utilise un large excès d'alcool : $n_2 = 0{,}50\ \text{mol}$.
\begin{enumerate}
    \item Quel est le réactif limitant ?
    \item À l'équilibre, on obtient $n_{ester,f} = 0{,}087\ \text{mol}$. Calculer le rendement par rapport à l'acide.
    \item Conclure sur l'effet de l'excès d'un réactif.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item L'acide est introduit en plus faible quantité ($0{,}10\ \text{mol} < 0{,}50\ \text{mol}$) : c'est le \textbf{réactif limitant}. Si la réaction était totale, on formerait $n_{ester,max} = 0{,}10\ \text{mol}$ d'ester.
    \item Le rendement par rapport au réactif limitant (l'acide) :
    \[
    r = \frac{n_{ester,f}}{n_{ester,max}} = \frac{0{,}087}{0{,}10} = 0{,}87 = 87\,\%
    \]
    \item L'excès d'un réactif \textbf{déplace l'équilibre dans le sens direct} (formation de l'ester) et \textbf{augmente le rendement} (de $67\,\%$ à $87\,\%$). En revanche, il ne modifie pas la nature limitée de la réaction.
\end{enumerate}

### Exercice 7 : Rôle du catalyseur et de la température
\begin{enonce}
Pour synthétiser un ester, on chauffe le mélange acide + alcool et on ajoute quelques gouttes d'acide sulfurique concentré (ions $\text{H}^+$).
\begin{enumerate}
    \item Quel est le rôle de la température ? Quel est le rôle des ions $\text{H}^+$ ?
    \item Ces deux facteurs modifient-ils le rendement de la réaction ? Justifier.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item La \textbf{température} augmente la vitesse de la réaction : l'équilibre est atteint plus rapidement. Les ions $\text{H}^+$ jouent le rôle de \textbf{catalyseur acide} : ils accélèrent aussi la réaction sans être consommés.
    \item \textbf{Non}, ni la température ni le catalyseur ne modifient le rendement. Ce sont des \textbf{facteurs cinétiques} : ils n'agissent que sur la vitesse (durée pour atteindre l'équilibre), pas sur l'état d'équilibre final. Comme la réaction est athermique, la composition à l'équilibre ne dépend quasiment pas de la température. Pour modifier le rendement, il faut jouer sur les quantités (excès d'un réactif, élimination de l'eau ou de l'ester).
\end{enumerate}

### Exercice 8 : Classe d'alcool et rendement
\begin{enonce}
On réalise l'estérification de l'acide éthanoïque avec, séparément, trois alcools en mélange équimolaire :
\begin{itemize}
    \item l'éthanol $\text{C}_2\text{H}_5\text{OH}$ (alcool primaire) ;
    \item le propan-2-ol (alcool secondaire) ;
    \item le 2-méthylpropan-2-ol (alcool tertiaire).
\end{itemize}
Les rendements à l'équilibre sont respectivement d'environ $67\,\%$, $60\,\%$ et $5\,\%$.

Que peut-on conclure sur l'influence de la classe de l'alcool ?
\end{enonce}

\textbf{Solution :}
Le rendement de l'estérification dépend de la classe de l'alcool utilisé. Pour un mélange équimolaire :
\begin{itemize}
    \item un alcool \textbf{primaire} donne le meilleur rendement (environ $67\,\%$) ;
    \item un alcool \textbf{secondaire} donne un rendement plus faible (environ $60\,\%$) ;
    \item un alcool \textbf{tertiaire} donne un très faible rendement (de l'ordre de $5\,\%$) et réagit très lentement.
\end{itemize}
Plus la classe de l'alcool est élevée, plus le rendement et la vitesse de l'estérification diminuent (à cause de l'encombrement autour du groupe $\text{OH}$).

### Exercice 1 : Vocabulaire de l'expression génétique
\begin{enonce}
Définir les termes suivants : **transcription**, **traduction**, **codon**, **ARN messager**, **ARN de transfert**, **anticodon**.
\end{enonce}

\textbf{Solution :}
\begin{itemize}
    \item **Transcription** : synthèse d'une molécule d'$\text{ARNm}$ dans le noyau, à partir d'un brin d'$\text{ADN}$ servant de modèle (brin transcrit).
    \item **Traduction** : synthèse d'une protéine dans le cytoplasme, par lecture de l'$\text{ARNm}$ au niveau des ribosomes.
    \item **Codon** : groupe de **trois nucléotides successifs** de l'$\text{ARNm}$ codant pour un acide aminé (ou un signal stop).
    \item **ARN messager ($\text{ARNm}$)** : molécule d'$\text{ARN}$ qui transporte l'information génétique du noyau vers le cytoplasme.
    \item **ARN de transfert ($\text{ARNt}$)** : petite molécule d'$\text{ARN}$ qui transporte un acide aminé spécifique vers le ribosome.
    \item **Anticodon** : triplet de nucléotides de l'$\text{ARNt}$ complémentaire du codon de l'$\text{ARNm}$.
\end{itemize}

### Exercice 2 : Comparaison ADN / ARN
\begin{enonce}
Comparer la molécule d'$\text{ADN}$ et la molécule d'$\text{ARN}$ en précisant au moins **trois** différences.
\end{enonce}

\textbf{Solution :}
\begin{itemize}
    \item **Nombre de brins** : l'$\text{ADN}$ est formé de **deux** brins (double hélice) ; l'$\text{ARN}$ est formé d'**un seul** brin.
    \item **Sucre (pentose)** : l'$\text{ADN}$ contient du **désoxyribose** ; l'$\text{ARN}$ contient du **ribose**.
    \item **Bases azotées** : l'$\text{ADN}$ contient les bases A, T, C, G ; l'$\text{ARN}$ contient A, U, C, G (la **thymine T est remplacée par l'uracile U**).
    \item **Localisation** : l'$\text{ADN}$ reste dans le noyau ; l'$\text{ARNm}$ peut quitter le noyau vers le cytoplasme.
\end{itemize}

### Exercice 3 : Transcription d'un brin d'ADN
\begin{enonce}
Un fragment du **brin transcrit** d'une molécule d'$\text{ADN}$ a pour séquence :
\[
\text{3'} - \text{T} - \text{A} - \text{C} - \text{G} - \text{G} - \text{A} - \text{T} - \text{T} - \text{5'}
\]
Écrire la séquence de l'$\text{ARNm}$ obtenu par transcription, en indiquant son orientation.
\end{enonce}

\textbf{Solution :}
L'$\text{ARNm}$ est synthétisé par **complémentarité** du brin transcrit : A↔U, T↔A, C↔G, G↔C (l'uracile U remplace la thymine en face de A). Le brin transcrit étant orienté $3' \rightarrow 5'$, l'$\text{ARNm}$ est lu et écrit dans le sens $5' \rightarrow 3'$ :
\[
\text{5'} - \text{A} - \text{U} - \text{G} - \text{C} - \text{C} - \text{U} - \text{A} - \text{A} - \text{3'}
\]

### Exercice 4 : Propriétés du code génétique
\begin{enonce}
Citer et expliquer brièvement **trois** propriétés du code génétique.
\end{enonce}

\textbf{Solution :}
\begin{itemize}
    \item **Universel** : un même codon code pour le même acide aminé chez la quasi-totalité des êtres vivants (bactéries, plantes, animaux).
    \item **Dégénéré (redondant)** : un même acide aminé peut être codé par **plusieurs codons** différents (ex. la leucine est codée par 6 codons), mais un codon ne code que pour un seul acide aminé.
    \item **Non chevauchant** : les codons sont lus **les uns à la suite des autres**, sans se chevaucher ; un nucléotide n'appartient qu'à un seul codon.
\end{itemize}

### Exercice 5 : De l'ARNm à la protéine
\begin{enonce}
Soit la séquence d'$\text{ARNm}$ suivante :
\[
\text{5'} - \text{A} \text{U} \text{G} - \text{G} \text{C} \text{U} - \text{U} \text{U} \text{U} - \text{U} \text{A} \text{A} - \text{3'}
\]
On donne le code génétique partiel : AUG = Méthionine (Met) ; GCU = Alanine (Ala) ; UUU = Phénylalanine (Phe) ; UAA = STOP.

Déterminer la séquence des acides aminés de la protéine obtenue par traduction.
\end{enonce}

\textbf{Solution :}
La lecture commence au **codon initiateur AUG** et se fait codon par codon dans le sens $5' \rightarrow 3'$ :
\begin{itemize}
    \item AUG $\rightarrow$ Méthionine (Met) ;
    \item GCU $\rightarrow$ Alanine (Ala) ;
    \item UUU $\rightarrow$ Phénylalanine (Phe) ;
    \item UAA $\rightarrow$ **codon stop** : il ne code aucun acide aminé et arrête la traduction.
\end{itemize}
La protéine est donc le **tripeptide** : Méthionine — Alanine — Phénylalanine.

### Exercice 6 : Rôle de l'ARN de transfert
\begin{enonce}
Au cours de la traduction, un codon de l'$\text{ARNm}$ a pour séquence $\text{5'} - \text{G} \text{C} \text{U} - \text{3'}$.
\begin{enumerate}
    \item Quel est l'anticodon de l'$\text{ARNt}$ qui reconnaît ce codon ?
    \item Quel acide aminé cet $\text{ARNt}$ transporte-t-il ? (On donne : GCU = Alanine.)
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item L'anticodon est **complémentaire et antiparallèle** au codon (A↔U, C↔G). Au codon $\text{5'} - \text{G} \text{C} \text{U} - \text{3'}$ correspond l'anticodon $\text{3'} - \text{C} \text{G} \text{A} - \text{5'}$.
    \item Cet $\text{ARNt}$ transporte l'acide aminé codé par GCU, c'est-à-dire l'**alanine**.
\end{enumerate}

### Exercice 7 : Mutation par substitution
\begin{enonce}
Un brin d'$\text{ARNm}$ normal possède le codon **UUU** (Phénylalanine). À la suite d'une mutation, ce codon devient **UCU**.
On donne : UUU = Phénylalanine ; UCU = Sérine.
\begin{enumerate}
    \item De quel type de mutation s'agit-il ?
    \item Quelle est la conséquence sur la protéine ?
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Un seul nucléotide a été remplacé par un autre (U $\rightarrow$ C) : il s'agit d'une **substitution**.
    \item Le codon UCU code la **sérine** au lieu de la phénylalanine : **un seul acide aminé change** dans la protéine. La mutation est **ponctuelle** et n'affecte pas le reste de la séquence (le cadre de lecture est conservé).
\end{enumerate}

### Exercice 8 : Mutation par addition et décalage du cadre de lecture
\begin{enonce}
Soit la séquence d'$\text{ARNm}$ normale :
\[
\text{5'} - \text{A} \text{U} \text{G} - \text{A} \text{A} \text{A} - \text{U} \text{U} \text{U} - \text{3'}
\]
À la suite d'une mutation, un nucléotide **G** est ajouté juste après le codon AUG, donnant :
\[
\text{5'} - \text{A} \text{U} \text{G} - \text{G} \text{A} \text{A} - \text{A} \text{U} \text{U} - \text{U} \ldots - \text{3'}
\]
Indiquer le type de mutation et sa conséquence sur la séquence des acides aminés.
\end{enonce}

\textbf{Solution :}
Un nucléotide a été **ajouté** : il s'agit d'une mutation par **addition** (insertion). L'ajout d'un nucléotide **décale le cadre de lecture** vers la droite : tous les codons situés en aval sont modifiés (AAA et UUU deviennent GAA, AUU, …). La séquence des acides aminés à partir du point de mutation est **entièrement changée**, ce qui produit en général une protéine **non fonctionnelle**. (Une **délétion**, perte d'un nucléotide, entraînerait le même type de décalage.)

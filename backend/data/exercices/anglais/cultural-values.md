### Exercice 6 : Collocations
\begin{enonce}
Match each verb or adjective on the left with the noun on the right to form a common collocation. Then write the full phrase.

Left: preserve, cultural, national, break down, shared
Right: stereotypes, heritage, diversity, identity, values
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item preserve + heritage → **preserve (our) heritage**
    \item cultural + diversity → **cultural diversity**
    \item national + identity → **national identity**
    \item break down + stereotypes → **break down stereotypes**
    \item shared + values → **shared values**
\end{enumerate}

### Exercice 7 : Odd one out
\begin{enonce}
In each line, three words belong to the same idea and one does not. Find the word that does not fit and explain why.
\begin{enumerate}
    \item tradition — custom — habit — globalization
    \item diversity — variety — uniformity — multiculturalism
    \item prejudice — stereotype — open-mindedness — bias
    \item heritage — ancestors — history — fashion
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item **globalization** — the others all refer to repeated, inherited ways of behaving.
    \item **uniformity** — it means *sameness*, the opposite of the other three, which all suggest variety.
    \item **open-mindedness** — it is a positive attitude, while the others are negative, fixed judgements.
    \item **fashion** — it is modern and changing, while the others belong to the past we inherit.
\end{enumerate}

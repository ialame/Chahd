### Exercice 1 : Zero conditional — general truths
\begin{enonce}
Put the verbs in brackets into the correct form to make zero conditionals. Remember: this type talks about facts and things that are always true.
\begin{enumerate}
    \item If you ___ (heat) ice, it ___ (melt).
    \item Plants ___ (die) if they ___ (not / get) enough water.
    \item If the sun ___ (set), the sky ___ (turn) dark.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
Zero conditional = **if + present simple, present simple**. Both clauses stay in the present.
\begin{enumerate}
    \item If you **heat** ice, it **melts**.
    \item Plants **die** if they **do not get** enough water.
    \item If the sun **sets**, the sky **turns** dark.
\end{enumerate}

### Exercice 2 : First conditional — real future
\begin{enonce}
Complete these sentences with the first conditional. They describe a real or possible situation in the future.
\begin{enumerate}
    \item If it ___ (rain) tomorrow, we ___ (stay) at home.
    \item She ___ (pass) the exam if she ___ (study) hard.
    \item If you ___ (not / hurry), you ___ (miss) the bus.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
First conditional = **if + present simple, will + base verb**. Note: never use *will* after *if*.
\begin{enumerate}
    \item If it **rains** tomorrow, we **will stay** at home.
    \item She **will pass** the exam if she **studies** hard.
    \item If you **do not hurry**, you **will miss** the bus.
\end{enumerate}

### Exercice 3 : Second conditional — unreal present
\begin{enonce}
Put the verbs into the second conditional to talk about an imaginary or unlikely situation.
\begin{enumerate}
    \item If I ___ (have) a million dirhams, I ___ (travel) around the world.
    \item She ___ (be) happier if she ___ (live) near the sea.
    \item If we ___ (know) the answer, we ___ (tell) you.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
Second conditional = **if + past simple, would + base verb**. With the verb *to be*, we use *were* for every subject.
\begin{enumerate}
    \item If I **had** a million dirhams, I **would travel** around the world.
    \item She **would be** happier if she **lived** near the sea.
    \item If we **knew** the answer, we **would tell** you.
\end{enumerate}

### Exercice 4 : Third conditional — unreal past
\begin{enonce}
Complete these sentences with the third conditional. They describe a past situation that did not happen and its imagined result.
\begin{enumerate}
    \item If you ___ (call) me, I ___ (help) you.
    \item They ___ (win) the match if they ___ (play) better.
    \item If I ___ (not / forget) my umbrella, I ___ (not / get) wet.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
Third conditional = **if + past perfect, would have + past participle**. It expresses regret about the past.
\begin{enumerate}
    \item If you **had called** me, I **would have helped** you.
    \item They **would have won** the match if they **had played** better.
    \item If I **had not forgotten** my umbrella, I **would not have got** wet.
\end{enumerate}

### Exercice 5 : Match the two halves
\begin{enonce}
Match each if-clause (1 to 4) with the correct result-clause (a to d). Write the letter next to each number.
\begin{enumerate}
    \item If you mix blue and yellow,
    \item If I were you,
    \item If he had studied medicine,
    \item If the weather is nice tomorrow,
\end{enumerate}
a. he would be a doctor now.
b. we will go for a picnic.
c. you get green.
d. I would accept the offer.
\end{enonce}

\textbf{Solution :}
Match each half by looking at the verb forms in both clauses.
\begin{enumerate}
    \item **c** (zero conditional — a scientific fact)
    \item **d** (second conditional — imaginary advice)
    \item **a** (third conditional — an unreal past)
    \item **b** (first conditional — a real future plan)
\end{enumerate}

### Exercice 6 : Turn the situation into a wish (present and past regret)
\begin{enonce}
Read each real situation and rewrite it using **wish** or **if only** to express a regret.
\begin{enumerate}
    \item I am not tall enough to join the team. (present)
    \item I do not speak Spanish. (present)
    \item I ate too much yesterday. (past)
    \item I did not revise for the test. (past)
\end{enumerate}
\end{enonce}

\textbf{Solution :}
For a present regret, use **wish + past simple**. For a past regret, use **wish + past perfect**.
\begin{enumerate}
    \item I **wish I were** tall enough to join the team.
    \item I **wish I spoke** Spanish. / **If only I spoke** Spanish.
    \item I **wish I had not eaten** so much yesterday.
    \item **If only I had revised** for the test.
\end{enumerate}

### Exercice 7 : Rewrite with "unless"
\begin{enonce}
Rewrite each sentence using **unless** instead of *if... not*, without changing the meaning.
\begin{enumerate}
    \item If you do not water the plants, they will die.
    \item She will not understand the lesson if she does not listen.
    \item If we do not leave now, we will be late.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
**Unless** means *if... not*. We drop the negative in the if-clause and keep the result-clause as it is.
\begin{enumerate}
    \item **Unless you water** the plants, they will die.
    \item She will not understand the lesson **unless she listens**.
    \item **Unless we leave** now, we will be late.
\end{enumerate}

### Exercice 8 : Correct the mistake
\begin{enonce}
Each sentence contains one mistake with conditionals or wishes. Find it and correct it.
\begin{enumerate}
    \item If it will rain tomorrow, we will stay home.
    \item If I was you, I would apologise.
    \item I wish I have more free time.
    \item If she had asked me, I would helped her.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
Check the verb form in each clause carefully.
\begin{enumerate}
    \item If it **rains** tomorrow, we will stay home. (no *will* after *if*)
    \item If I **were** you, I would apologise. (*were* in the second conditional)
    \item I wish I **had** more free time. (*wish* + past simple for a present regret)
    \item If she had asked me, I **would have helped** her. (third conditional needs *would have* + past participle)
\end{enumerate}

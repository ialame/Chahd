### Exercice 1 : Active to passive — present simple
\begin{enonce}
Rewrite these sentences in the passive voice.
\begin{enumerate}
    \item The teacher corrects the exercises every day.
    \item People speak English all over the world.
    \item The company produces thousands of cars each year.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
The verb becomes **am/is/are + past participle**; the object moves to the front.
\begin{enumerate}
    \item The exercises **are corrected** (by the teacher) every day.
    \item English **is spoken** all over the world.
    \item Thousands of cars **are produced** (by the company) each year.
\end{enumerate}

### Exercice 2 : Active to passive — past simple
\begin{enonce}
Rewrite these sentences in the passive voice.
\begin{enumerate}
    \item Workers built this bridge in 1990.
    \item A famous architect designed the museum.
    \item Someone stole my bicycle last night.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
Past simple passive = **was/were + past participle**.
\begin{enumerate}
    \item This bridge **was built** in 1990.
    \item The museum **was designed** by a famous architect.
    \item My bicycle **was stolen** last night. (the agent is unknown, so no *by*)
\end{enumerate}

### Exercice 3 : Passive with the present perfect
\begin{enonce}
Put the verb in brackets into the correct passive form (present perfect).
\begin{enumerate}
    \item A new vaccine ___ (discover).
    \item The results ___ (not / publish) yet.
    \item How many books ___ (translate) into Arabic?
\end{enumerate}
\end{enonce}

\textbf{Solution :}
Present perfect passive = **has/have been + past participle**.
\begin{enumerate}
    \item A new vaccine **has been discovered**.
    \item The results **have not been published** yet.
    \item How many books **have been translated** into Arabic?
\end{enumerate}

### Exercice 4 : Passive with modal verbs
\begin{enonce}
Rewrite in the passive voice.
\begin{enumerate}
    \item You must finish the report today.
    \item People can solve this problem easily.
    \item We should protect the environment.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
Modal passive = **modal + be + past participle**.
\begin{enumerate}
    \item The report **must be finished** today.
    \item This problem **can be solved** easily.
    \item The environment **should be protected**.
\end{enumerate}

### Exercice 5 : Passive to active
\begin{enonce}
Rewrite these passive sentences in the active voice. The agent is given.
\begin{enumerate}
    \item The letter was written by Sara.
    \item The match is watched by millions of people.
    \item The windows have been cleaned by the workers.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
The agent becomes the subject; the verb returns to the active form.
\begin{enumerate}
    \item Sara **wrote** the letter.
    \item Millions of people **watch** the match.
    \item The workers **have cleaned** the windows.
\end{enumerate}

### Exercice 6 : When to use the passive
\begin{enonce}
For each sentence, decide whether the passive is more natural than the active, and justify briefly.
\begin{enumerate}
    \item (Someone / robbed) the bank yesterday.
    \item (My grandfather / planted) this tree.
    \item (They / produce) olive oil in this region.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item **Passive**: *The bank was robbed yesterday.* The agent is unknown and not important.
    \item **Active**: *My grandfather planted this tree.* The agent is known and meaningful, so we keep it as the subject.
    \item **Passive**: *Olive oil is produced in this region.* The focus is on the product, not on the people, so *by them* is dropped.
\end{enumerate}

### Exercice 7 : The passive of reporting verbs
\begin{enonce}
Rewrite using the impersonal passive, in the two possible structures.
\begin{enumerate}
    \item People say that he is very rich.
    \item Experts believe that the economy will improve.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
Two patterns: **It + is + past participle + that...** and **Subject + is + past participle + to + infinitive**.
\begin{enumerate}
    \item **It is said that** he is very rich. / He **is said to be** very rich.
    \item **It is believed that** the economy will improve. / The economy **is believed to improve** (soon).
\end{enumerate}

### Exercice 8 : Correct the mistake
\begin{enonce}
Each sentence contains one passive-voice mistake. Correct it.
\begin{enumerate}
    \item The cake was make by my mother.
    \item English is speak in many countries.
    \item The thief was arrest by the police.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
The passive needs the **past participle**, not the base form.
\begin{enumerate}
    \item The cake was **made** by my mother.
    \item English is **spoken** in many countries.
    \item The thief was **arrested** by the police.
\end{enumerate}

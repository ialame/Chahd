### Exercice 1 : Équilibrer des équations de réaction
\begin{enonce}
Équilibrer chacune des équations de réaction suivantes en ajustant les coefficients stœchiométriques :
\begin{enumerate}
    \item $H_2 + O_2 \longrightarrow H_2O$
    \item $C_4H_{10} + O_2 \longrightarrow CO_2 + H_2O$
    \item $Fe + O_2 \longrightarrow Fe_2O_3$
    \item $Al + HCl \longrightarrow AlCl_3 + H_2$
\end{enumerate}
\end{enonce}

\textbf{Solution :}
On agit uniquement sur les coefficients, jamais sur les indices des formules.
\begin{enumerate}
    \item $2\,H_2 + O_2 \longrightarrow 2\,H_2O$ : on a $4$ atomes de $H$ et $2$ atomes de $O$ de chaque côté.
    \item $2\,C_4H_{10} + 13\,O_2 \longrightarrow 8\,CO_2 + 10\,H_2O$ : carbone $8 = 8$, hydrogène $20 = 20$, oxygène $26 = 16 + 10 = 26$.
    \item $4\,Fe + 3\,O_2 \longrightarrow 2\,Fe_2O_3$ : fer $4 = 4$, oxygène $6 = 6$.
    \item $2\,Al + 6\,HCl \longrightarrow 2\,AlCl_3 + 3\,H_2$ : aluminium $2 = 2$, chlore $6 = 6$, hydrogène $6 = 6$.
\end{enumerate}

### Exercice 2 : Tableau d'avancement de la combustion du carbone
\begin{enonce}
On fait brûler du carbone dans du dioxygène selon l'équation $C + O_2 \longrightarrow CO_2$. À l'état initial, le système contient $n_0(C) = 2{,}0\ \text{mol}$ de carbone et $n_0(O_2) = 3{,}0\ \text{mol}$ de dioxygène.
\begin{enumerate}
    \item Dresser le tableau d'avancement de la transformation.
    \item Déterminer l'avancement maximal $x_{max}$ et le réactif limitant.
    \item Donner le bilan de matière à l'état final.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Tableau d'avancement (quantités en mol) :

| Équation | $C$ | $+\ O_2$ | $\longrightarrow$ | $CO_2$ |
|---|---|---|---|---|
| État initial ($x=0$) | $2{,}0$ | $3{,}0$ | | $0$ |
| En cours ($x$) | $2{,}0 - x$ | $3{,}0 - x$ | | $x$ |
| État final ($x_{max}$) | $2{,}0 - x_{max}$ | $3{,}0 - x_{max}$ | | $x_{max}$ |

    \item Le carbone s'annule pour $x = \dfrac{2{,}0}{1} = 2{,}0\ \text{mol}$ et le dioxygène pour $x = \dfrac{3{,}0}{1} = 3{,}0\ \text{mol}$. L'avancement maximal est la plus petite valeur :
    $$x_{max} = \min(2{,}0\,;\ 3{,}0) = 2{,}0\ \text{mol}$$
    Le **carbone** est le réactif limitant.
    \item Bilan de matière à l'état final : $n(C) = 2{,}0 - 2{,}0 = 0\ \text{mol}$ ; $n(O_2) = 3{,}0 - 2{,}0 = 1{,}0\ \text{mol}$ (excès) ; $n(CO_2) = 2{,}0\ \text{mol}$.
\end{enumerate}

### Exercice 3 : Synthèse de l'ammoniac
\begin{enonce}
La synthèse de l'ammoniac est modélisée par l'équation $N_2 + 3\,H_2 \longrightarrow 2\,NH_3$. On introduit $n_0(N_2) = 2{,}0\ \text{mol}$ de diazote et $n_0(H_2) = 3{,}0\ \text{mol}$ de dihydrogène.
\begin{enumerate}
    \item Déterminer l'avancement maximal et le réactif limitant.
    \item Quelle quantité d'ammoniac se forme-t-il ?
    \item Établir le bilan de matière à l'état final.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Le diazote s'annule pour $x = \dfrac{n_0(N_2)}{1} = \dfrac{2{,}0}{1} = 2{,}0\ \text{mol}$ et le dihydrogène pour $x = \dfrac{n_0(H_2)}{3} = \dfrac{3{,}0}{3} = 1{,}0\ \text{mol}$. Donc :
    $$x_{max} = \min(2{,}0\,;\ 1{,}0) = 1{,}0\ \text{mol}$$
    Le **dihydrogène** est le réactif limitant.
    \item La quantité d'ammoniac formée vaut $n(NH_3) = 2\,x_{max} = 2 \times 1{,}0 = 2{,}0\ \text{mol}$.
    \item Bilan : $n(N_2) = 2{,}0 - 1{,}0 = 1{,}0\ \text{mol}$ (excès) ; $n(H_2) = 3{,}0 - 3 \times 1{,}0 = 0\ \text{mol}$ (limitant) ; $n(NH_3) = 2{,}0\ \text{mol}$.
\end{enumerate}

### Exercice 4 : Mélange stœchiométrique
\begin{enonce}
On réalise la synthèse de l'eau selon $2\,H_2 + O_2 \longrightarrow 2\,H_2O$. On dispose de $n_0(H_2) = 6{,}0\ \text{mol}$ de dihydrogène.
\begin{enumerate}
    \item Quelle quantité de dioxygène faut-il introduire pour que le mélange soit stœchiométrique ?
    \item Dans ces conditions, déterminer $x_{max}$ et la quantité d'eau formée.
    \item Que reste-t-il des réactifs à l'état final ?
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Le mélange est stœchiométrique lorsque $\dfrac{n_0(H_2)}{2} = \dfrac{n_0(O_2)}{1}$, soit $n_0(O_2) = \dfrac{n_0(H_2)}{2} = \dfrac{6{,}0}{2} = 3{,}0\ \text{mol}$.
    \item Les deux réactifs s'annulent pour la même valeur $x_{max} = \dfrac{6{,}0}{2} = \dfrac{3{,}0}{1} = 3{,}0\ \text{mol}$. La quantité d'eau formée est $n(H_2O) = 2\,x_{max} = 6{,}0\ \text{mol}$.
    \item Dans un mélange stœchiométrique, les deux réactifs sont entièrement consommés : $n(H_2) = 0$ et $n(O_2) = 0$. Il ne reste aucun réactif en excès.
\end{enumerate}

### Exercice 5 : Volume de gaz dégagé
\begin{enonce}
On verse de l'acide chlorhydrique sur du zinc selon $Zn + 2\,HCl \longrightarrow ZnCl_2 + H_2$. Le système contient initialement $n_0(Zn) = 0{,}10\ \text{mol}$ de zinc et $n_0(HCl) = 0{,}30\ \text{mol}$ d'acide. On donne le volume molaire $V_m = 24\ \text{L}\cdot\text{mol}^{-1}$.
\begin{enumerate}
    \item Déterminer l'avancement maximal et le réactif limitant.
    \item En déduire la quantité de dihydrogène formée.
    \item Calculer le volume de dihydrogène dégagé.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Le zinc s'annule pour $x = \dfrac{0{,}10}{1} = 0{,}10\ \text{mol}$ et l'acide pour $x = \dfrac{0{,}30}{2} = 0{,}15\ \text{mol}$. Donc :
    $$x_{max} = \min(0{,}10\,;\ 0{,}15) = 0{,}10\ \text{mol}$$
    Le **zinc** est le réactif limitant.
    \item La quantité de dihydrogène formée est $n(H_2) = x_{max} = 0{,}10\ \text{mol}$.
    \item Le volume dégagé vaut $V(H_2) = n(H_2) \times V_m = 0{,}10 \times 24 = 2{,}4\ \text{L}$.
\end{enumerate}

### Exercice 6 : Bilan de matière de la combustion du méthane
\begin{enonce}
La combustion complète du méthane s'écrit $CH_4 + 2\,O_2 \longrightarrow CO_2 + 2\,H_2O$. On part de $n_0(CH_4) = 0{,}20\ \text{mol}$ de méthane et $n_0(O_2) = 0{,}50\ \text{mol}$ de dioxygène.
\begin{enumerate}
    \item Déterminer le réactif limitant et l'avancement maximal.
    \item Établir le bilan de matière complet à l'état final.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Le méthane s'annule pour $x = \dfrac{0{,}20}{1} = 0{,}20\ \text{mol}$ et le dioxygène pour $x = \dfrac{0{,}50}{2} = 0{,}25\ \text{mol}$. Donc :
    $$x_{max} = \min(0{,}20\,;\ 0{,}25) = 0{,}20\ \text{mol}$$
    Le **méthane** est le réactif limitant.
    \item Bilan de matière à l'état final :
    \begin{itemize}
        \item $n(CH_4) = 0{,}20 - 0{,}20 = 0\ \text{mol}$ (limitant) ;
        \item $n(O_2) = 0{,}50 - 2 \times 0{,}20 = 0{,}10\ \text{mol}$ (excès) ;
        \item $n(CO_2) = 0{,}20\ \text{mol}$ ;
        \item $n(H_2O) = 2 \times 0{,}20 = 0{,}40\ \text{mol}$.
    \end{itemize}
\end{enumerate}

### Exercice 1 : Trouver la période et le groupe
\begin{enonce}
On donne les numéros atomiques de trois éléments : le bore $\text{B}$ ($Z=5$), le magnésium $\text{Mg}$ ($Z=12$) et le chlore $\text{Cl}$ ($Z=17$).
\begin{enumerate}
    \item Écrire la structure électronique $(\text{K})\ldots(\text{L})\ldots(\text{M})\ldots$ de chaque atome.
    \item En déduire, pour chacun, le numéro de la **période** (la ligne).
    \item Donner le nombre d'**électrons de valence** de chaque atome, puis son numéro de **groupe** (la colonne).
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item On répartit les électrons en remplissant les couches $\text{K}$ (2 au maximum), puis $\text{L}$ (8 au maximum), puis $\text{M}$ :
\begin{itemize}
    \item $\text{B}$ : $(\text{K})^2(\text{L})^3$ ;
    \item $\text{Mg}$ : $(\text{K})^2(\text{L})^8(\text{M})^2$ ;
    \item $\text{Cl}$ : $(\text{K})^2(\text{L})^8(\text{M})^7$.
\end{itemize}
    \item Le numéro de la période est égal au **nombre de couches occupées** : le bore occupe 2 couches → **2\textsuperscript{e} période** ; le magnésium et le chlore occupent 3 couches → **3\textsuperscript{e} période**.
    \item Le nombre d'électrons de valence est le nombre d'électrons de la **dernière couche** :
\begin{itemize}
    \item $\text{B}$ : 3 électrons de valence → **groupe 13** ($3+10$) ;
    \item $\text{Mg}$ : 2 électrons de valence → **groupe 2** ;
    \item $\text{Cl}$ : 7 électrons de valence → **groupe 17** ($7+10$).
\end{itemize}
\end{enumerate}

### Exercice 2 : Reconnaître les familles
\begin{enonce}
On considère les éléments suivants : le sodium $\text{Na}$ ($Z=11$), le fluor $\text{F}$ ($Z=9$), l'argon $\text{Ar}$ ($Z=18$) et le potassium $\text{K}$ ($Z=19$).
\begin{enumerate}
    \item Donner la structure électronique de chacun.
    \item À quelle famille (alcalins, halogènes ou gaz nobles) appartient chaque élément ?
    \item Quels sont les deux éléments qui appartiennent à la **même famille** ? Justifier.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Structures électroniques :
\begin{itemize}
    \item $\text{F}$ : $(\text{K})^2(\text{L})^7$ ;
    \item $\text{Na}$ : $(\text{K})^2(\text{L})^8(\text{M})^1$ ;
    \item $\text{Ar}$ : $(\text{K})^2(\text{L})^8(\text{M})^8$ ;
    \item $\text{K}$ : $(\text{K})^2(\text{L})^8(\text{M})^8(\text{N})^1$.
\end{itemize}
    \item On reconnaît chaque famille au nombre d'électrons de valence :
\begin{itemize}
    \item $\text{Na}$ (1 électron de valence, groupe 1) → **alcalin** ;
    \item $\text{F}$ (7 électrons de valence, groupe 17) → **halogène** ;
    \item $\text{Ar}$ (8 électrons de valence, dernière couche saturée, groupe 18) → **gaz noble** ;
    \item $\text{K}$ (1 électron de valence, groupe 1) → **alcalin**.
\end{itemize}
    \item Le sodium $\text{Na}$ et le potassium $\text{K}$ appartiennent à la **même famille (les alcalins)** : ils possèdent tous deux **1 seul électron de valence**, donc occupent la même colonne (groupe 1) et ont des propriétés chimiques voisines.
\end{enumerate}

### Exercice 3 : Prévoir les ions
\begin{enonce}
À partir de leur place dans la classification, on veut prévoir l'ion stable que forment les éléments suivants : le magnésium $\text{Mg}$ ($Z=12$), l'oxygène $\text{O}$ ($Z=8$) et le potassium $\text{K}$ ($Z=19$).
\begin{enumerate}
    \item Pour chaque atome, indiquer son nombre d'électrons de valence.
    \item En déduire s'il va **perdre** ou **gagner** des électrons pour atteindre la structure d'un gaz noble.
    \item Écrire la formule de l'ion formé et préciser s'il s'agit d'un cation ou d'un anion.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Structures et électrons de valence :
\begin{itemize}
    \item $\text{Mg}$ : $(\text{K})^2(\text{L})^8(\text{M})^2$ → 2 électrons de valence ;
    \item $\text{O}$ : $(\text{K})^2(\text{L})^6$ → 6 électrons de valence ;
    \item $\text{K}$ : $(\text{K})^2(\text{L})^8(\text{M})^8(\text{N})^1$ → 1 électron de valence.
\end{itemize}
    \item Pour atteindre l'octet (ou le duet) du gaz noble le plus proche :
\begin{itemize}
    \item $\text{Mg}$ a peu d'électrons de valence (2) : il les **perd** ;
    \item $\text{K}$ a peu d'électrons de valence (1) : il le **perd** ;
    \item $\text{O}$ a beaucoup d'électrons de valence (6) : il **gagne** 2 électrons pour compléter l'octet.
\end{itemize}
    \item Ions formés :
\begin{itemize}
    \item $\text{Mg} \rightarrow \text{Mg}^{2+}$ : **cation** (structure du néon) ;
    \item $\text{O} \rightarrow \text{O}^{2-}$ : **anion** (structure du néon) ;
    \item $\text{K} \rightarrow \text{K}^{+}$ : **cation** (structure de l'argon).
\end{itemize}
\end{enumerate}

### Exercice 4 : Lire un extrait du tableau
\begin{enonce}
Voici un extrait de la classification périodique (numéros atomiques entre parenthèses) :

| Période \ Groupe | 1 | 2 | 13 | 17 | 18 |
|---|---|---|---|---|---|
| 2 | Li (3) | Be (4) | B (5) | F (9) | Ne (10) |
| 3 | Na (11) | Mg (12) | Al (13) | Cl (17) | Ar (18) |

\begin{enumerate}
    \item Sans calcul, donner le nombre d'électrons de valence d'un élément de la colonne 13. Vérifier avec l'aluminium $\text{Al}$ ($Z=13$).
    \item Citer deux éléments de cet extrait appartenant à la famille des halogènes.
    \item Un élément $\text{X}$ se trouve sur la 3\textsuperscript{e} période, dans le groupe 2. De quel élément s'agit-il ?
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Les éléments du groupe 13 possèdent $13-10 = \mathbf{3}$ électrons de valence. Vérification : $\text{Al}$ a pour structure $(\text{K})^2(\text{L})^8(\text{M})^3$, sa dernière couche $\text{M}$ porte bien **3 électrons** de valence.
    \item Les halogènes occupent le groupe 17 : ce sont le **fluor $\text{F}$** et le **chlore $\text{Cl}$**.
    \item L'intersection de la 3\textsuperscript{e} période et du groupe 2 donne le **magnésium $\text{Mg}$** ($Z=12$).
\end{enumerate}

### Exercice 5 : La famille des alcalins
\begin{enonce}
Le lithium $\text{Li}$ ($Z=3$), le sodium $\text{Na}$ ($Z=11$) et le potassium $\text{K}$ ($Z=19$) appartiennent à la famille des alcalins.
\begin{enumerate}
    \item Donner leur structure électronique et vérifier qu'ils ont tous le **même nombre d'électrons de valence**.
    \item Pourquoi ces trois éléments ont-ils des propriétés chimiques **semblables** ?
    \item Les alcalins réagissent vivement avec l'eau. Quel ion chacun forme-t-il au cours de la réaction ?
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Structures électroniques :
\begin{itemize}
    \item $\text{Li}$ : $(\text{K})^2(\text{L})^1$ ;
    \item $\text{Na}$ : $(\text{K})^2(\text{L})^8(\text{M})^1$ ;
    \item $\text{K}$ : $(\text{K})^2(\text{L})^8(\text{M})^8(\text{N})^1$.
\end{itemize}
Chacun possède **1 seul électron** sur sa dernière couche : ils ont tous **1 électron de valence**.
    \item Les propriétés chimiques d'un élément dépendent essentiellement de ses **électrons de valence**. Comme les trois alcalins en ont le même nombre (1), ils occupent la même colonne (groupe 1) et se comportent de manière **comparable**.
    \item Chaque alcalin **perd** son unique électron de valence pour former un cation de charge $+1$ : $\text{Li}^{+}$, $\text{Na}^{+}$ et $\text{K}^{+}$.
\end{enumerate}

### Exercice 6 : Valence et liaisons covalentes
\begin{enonce}
On s'intéresse au carbone $\text{C}$ ($Z=6$), à l'oxygène $\text{O}$ ($Z=8$) et à l'hydrogène $\text{H}$ ($Z=1$).
\begin{enumerate}
    \item Donner pour chacun son nombre d'électrons de valence.
    \item Le nombre de liaisons covalentes que forme un atome est le nombre d'électrons qui lui **manquent** pour atteindre le duet ou l'octet. En déduire le nombre de liaisons de $\text{C}$, $\text{O}$ et $\text{H}$.
    \item Vérifier que ces nombres sont cohérents avec la formule de la molécule de méthane $\text{CH}_4$ et celle de l'eau $\text{H}_2\text{O}$.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Électrons de valence :
\begin{itemize}
    \item $\text{H}$ : $(\text{K})^1$ → 1 électron de valence ;
    \item $\text{C}$ : $(\text{K})^2(\text{L})^4$ → 4 électrons de valence ;
    \item $\text{O}$ : $(\text{K})^2(\text{L})^6$ → 6 électrons de valence.
\end{itemize}
    \item Nombre de liaisons (électrons manquants pour le duet/octet) :
\begin{itemize}
    \item $\text{H}$ : il lui manque $2-1=1$ électron pour le duet → **1 liaison** ;
    \item $\text{C}$ : il lui manque $8-4=4$ électrons pour l'octet → **4 liaisons** ;
    \item $\text{O}$ : il lui manque $8-6=2$ électrons pour l'octet → **2 liaisons**.
\end{itemize}
    \item Dans $\text{CH}_4$, le carbone forme bien **4 liaisons** (une avec chacun des 4 atomes $\text{H}$), et chaque $\text{H}$ une seule liaison. Dans $\text{H}_2\text{O}$, l'oxygène forme **2 liaisons** (une avec chacun des 2 atomes $\text{H}$). Les formules sont donc cohérentes avec les valences prévues par la classification.
\end{enumerate}

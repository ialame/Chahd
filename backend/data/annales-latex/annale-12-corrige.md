<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 1 <span class="font-normal text-white/80 text-sm">(7 points)</span></div>
**Partie 1.** **1.1.** Équation de la réaction : $CH_3COOH_{(aq)} + H_2O_{(l)} \rightleftharpoons CH_3COO^-_{(aq)} + H_3O^+_{(aq)}$.

**1.2.** À l'aide du tableau d'avancement : $\alpha = 1 - \tau = 1 - \dfrac{10^{-pH}}{C_A}$. Application : $\alpha = 1 - \dfrac{10^{-3{,}05}}{5\cdot10^{-2}} = 0{,}982$, soit $\alpha = 98{,}2\,\%$.

**1.3.** $K_{A1} = \dfrac{10^{-2pH}}{C_A - 10^{-pH}}$ d'où $pK_{A1} = -\log\dfrac{10^{-2\times3{,}05}}{5\cdot10^{-2} - 10^{-3{,}05}} \Rightarrow pK_{A1} = 4{,}79$.

**Partie 2.** **2.1.** Équation de la réaction : $CH_3COOH_{(aq)} + HCOO^-_{(aq)} \rightleftharpoons CH_3COO^-_{(aq)} + HCOOH_{(aq)}$.

**2.2.** $Q_{r,\text{éq}} = \dfrac{K_{A1}}{K_{A2}} = 10^{pK_{A2} - pK_{A1}} = 10^{3{,}75 - 4{,}79} = 0{,}091$, soit $Q_{r,\text{éq}} = 9{,}1\cdot10^{-2}$.

**2.3.** $pH = \dfrac{1}{2}(pK_{A1} + pK_{A2}) = \dfrac{1}{2}(4{,}79 + 3{,}75) \Rightarrow pH = 4{,}27$.

**Partie 3.** **3.1.** Réaction d'estérification : $CH_3COOH + CH_3OH \rightleftharpoons CH_3COOCH_3 + H_2O$.

**3.2.** La courbe $C_1$ correspond à la réaction utilisant le catalyseur : la réaction atteint son état final dans une durée plus courte.

**3.3.** Composition à l'équilibre : $n_{af} = 0{,}3~\mathrm{mol}$ d'acide restant ; $x_f = 0{,}9 - 0{,}3 = 0{,}6~\mathrm{mol}$ d'ester (et d'eau) formé.

**3.4.** Temps de demi-réaction (courbe $C_2$) : $x(t_{1/2}) = \dfrac{x_f}{2} = 0{,}3~\mathrm{mol}$ ; par projection $t_{1/2} = 3{,}5~\mathrm{h}$.

**3.5.** Rendement : $r = \dfrac{x_f}{x_{max}} = \dfrac{0{,}6}{0{,}9} = 0{,}667$, soit $r = 66{,}7\,\%$.

**3.6.** Avec $K = 4$, on résout $3x_{\text{éq}}^2 - 4x_{\text{éq}} + 0{,}12 = 0 \Rightarrow x_{\text{éq}} = 0{,}03~\mathrm{mol}$ ; nouveau rendement $r' = \dfrac{0{,}6 + 0{,}03}{0{,}6 + 0{,}3} = 0{,}70$, soit $r' = 70\,\%$.

**1.1.** Affirmations : A — **Faux** ; B — **Faux** ; C — **Faux** ; D — **Faux** ; E — **Vrai**.

**1.2.** Équation de désintégration : $^{3}_{1}\mathrm{H} \longrightarrow\ ^{3}_{2}\mathrm{He} + \ ^{\;0}_{-1}\mathrm{e}$ (type $\beta^-$).

**1.3.** Relation demi-vie / constante radioactive : $t_{1/2} = \dfrac{\ln 2}{\lambda}$.

**1.4.** Quand $90\,\%$ des noyaux sont désintégrés, $N_1 = 0{,}1\,N_0$ ; $a_1 = 0{,}1\,\lambda\,N_0 = 0{,}1\cdot\dfrac{\ln 2}{t_{1/2}}\cdot\dfrac{m_0\,N_A}{M(^{3}_{1}\mathrm{H})}$. Application : $a_1 = 7{,}15\cdot10^{8}~\mathrm{Bq}$.

**2.1.** **a — Vrai** : l'énergie de dissociation du tritium vaut son énergie de liaison $E_\ell(^{3}_{1}\mathrm{H}) = 8{,}475~\mathrm{MeV}$. **b — Vrai** : $\dfrac{E_\ell(^{3}_{1}\mathrm{H})}{3} = 2{,}825 > \dfrac{E_\ell(^{2}_{1}\mathrm{H})}{2} = 1{,}183~\mathrm{MeV/nucléon}$, le tritium est plus stable.

**2.2.** $^{3}_{1}\mathrm{H} + \ ^{2}_{1}\mathrm{H} \longrightarrow\ ^{4}_{2}\mathrm{He} + \ ^{1}_{0}\mathrm{n}$ ; $E_{lib} = |\Delta E| = |8{,}475 + 2{,}366 - 28{,}296| = 17{,}455~\mathrm{MeV} \Rightarrow E_{lib} = 17{,}46~\mathrm{MeV}$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 3 <span class="font-normal text-white/80 text-sm">(5 points)</span></div>
**1.1.** Équation différentielle : $\dfrac{di}{dt} + \dfrac{R}{L}\,i = \dfrac{E}{L}$.

**1.2.1.** $A = \dfrac{E}{R}$ et $B = -\dfrac{E}{R}$, d'où $i(t) = \dfrac{E}{R}\left(1 - e^{-\frac{t}{\tau}}\right)$ avec $\tau = \dfrac{L}{R}$.

**1.2.2.** $L = \tau\cdot\dfrac{E}{I_0}$ ; avec $\tau = 2~\mathrm{ms}$ et $I_0 = 48~\mathrm{mA}$, on obtient $L = 1~\mathrm{H}$.

**1.3.** Tension aux bornes de la bobine : $u_L(t) = E\,e^{-\frac{t}{\tau}} = 24\,e^{-500\,t}$ (SI).

**2.1.** Équation différentielle : $\dfrac{d^{2}u_C}{dt^{2}} + \dfrac{1}{L\,C}\,u_C = 0$.

**2.2.1.** $C = \dfrac{T_0^2}{4\pi^2 L}$ ; avec $T_0 = 2~\mathrm{ms}$ et $\pi^2 = 10$ : $C = 10^{-7}~\mathrm{F} = 0{,}1~\mathrm{\mu F}$.

**2.2.2.** $E_m(t) = \dfrac{1}{2}\,C\left(u_{C\,max}^2 - u_C^2(t)\right) = \dfrac{1}{2}\times10^{-7}\times(10^2 - 8^2) \Rightarrow E_m = 1{,}8\cdot10^{-6}~\mathrm{J}$.

**3.1.** Proposition juste : **B**. ($T_s = 5~\mathrm{ms} \Rightarrow f_s = 200~\mathrm{Hz}$ ; $T_s = 20\,T_p \Rightarrow f_p = 20\,f_s = 4~\mathrm{kHz}$.)

**3.2.** **a — Faux** : $m = \dfrac{U_{m\,max} - U_{m\,min}}{U_{m\,max} + U_{m\,min}} = \dfrac{6 - 2}{6 + 2} = 0{,}5$. **b — Faux** : $U_0 = \dfrac{U_{m\,max} + U_{m\,min}}{2} = \dfrac{6 + 2}{2} = 4~\mathrm{V}$.

**3.3.** Spectre de fréquences : trois raies aux fréquences $f_p - f_s = 3{,}8~\mathrm{kHz}$, $f_p = 4~\mathrm{kHz}$ et $f_p + f_s = 4{,}2~\mathrm{kHz}$ (raies latérales d'amplitude $\dfrac{A\,m}{2}$, raie centrale d'amplitude $A$).

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 4 <span class="font-normal text-white/80 text-sm">(5,5 points)</span></div>
**Partie 1.** **1.1.** Équations horaires : $v_z(t) = -10\,t + 12$ et $z(t) = -5\,t^2 + 12\,t$.

**1.2.1.** Hauteur maximale (à $v_z = 0$, $t_1 = 1{,}2~\mathrm{s}$) : $h = z(t_1) = 7{,}2~\mathrm{m}$.

**1.2.2.** Passage par $O$ vers le bas ($t_2 = 2{,}4~\mathrm{s}$) : $v_{Oz} = v_z(t_2) = -12~\mathrm{m\cdot s^{-1}}$.

**2.1.** Équation différentielle : $\dfrac{dv_z}{dt} + \dfrac{1}{\tau}\,v_z + g = 0$ avec $\tau = \dfrac{m}{\lambda}$.

**2.2.** Vitesse limite : $v_{\ell im} = \left|\dfrac{-m\,g}{\lambda}\right| = \left|\dfrac{-80\cdot10^{-3}\times10}{0{,}12}\right| \Rightarrow v_{\ell im} = 6{,}67~\mathrm{m\cdot s^{-1}}$.

**2.3.** Méthode d'Euler : $v_{i-1} = -\dfrac{m}{\lambda}(a_{i-1} + 1) = -10~\mathrm{m\cdot s^{-1}}$ ; $v_z(t_i) = v_{i-1} + a_{i-1}\,\Delta t = -10 + 5\times66\cdot10^{-3} \Rightarrow v_z(t_i) = -9{,}67~\mathrm{m\cdot s^{-1}}$.

**Partie 2.** **1.** $E_{pp} = m\,g\,z$ avec $z = \ell(1 - \cos\theta) \approx \ell\dfrac{\theta^2}{2}$, d'où $E_{pp} = \dfrac{1}{2}\,m\,g\,\ell\,\theta^2$.

**2.1.** Conservation de l'énergie : $\ell\,\dot{\theta}_{max}^2 = g\,\theta_0^2$ d'où $\dot{\theta}_{max} = \theta_0\sqrt{\dfrac{g}{\ell}} = 9^\circ\times\dfrac{\pi}{180^\circ}\sqrt{\dfrac{10}{2{,}4}} \Rightarrow \dot{\theta}_{max} = 0{,}32~\mathrm{rad\cdot s^{-1}}$.

**2.2.** Équation différentielle : $\dfrac{d^{2}\theta}{dt^{2}} + \dfrac{g}{\ell}\,\theta = 0$.

**3.** Période propre : $T_0 = 2\pi\sqrt{\dfrac{\ell}{g}} = 2\pi\sqrt{\dfrac{2{,}4}{10}} \Rightarrow T_0 = 3{,}08~\mathrm{s}$.

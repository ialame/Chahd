<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 1 <span class="font-normal text-white/80 text-sm">(7 points)</span></div>
**Partie 1.** **1.1.** Équation de la réaction de dosage : $NH_{3(aq)} + H_3O^+_{(aq)} \longrightarrow NH_{4(aq)}^+ + H_2O_{(l)}$.

**1.2.** À l'équivalence : $n_i(NH_3) = n_E(H_3O^+)$, d'où $C_b\,V_b = C_a\,V_{aE}$.

**1.3.** $C_b = \dfrac{C_a\,V_{aE}}{V_b}$ ; graphiquement $V_{aE} = 15~\mathrm{mL}$ donc $C_b = 10^{-2}~\mathrm{mol\cdot L^{-1}}$ ; et $C_0 = 100\,C_b = 1~\mathrm{mol\cdot L^{-1}}$.

**1.4.** Graphiquement $pH_E \approx 6$ : l'indicateur adéquat est le **rouge de méthyle** ($4{,}2 < pH_E < 6{,}2$).

**2.1.** Équation de la réaction de l'ammoniac avec l'eau : $NH_{3(aq)} + H_2O_{(l)} \rightleftarrows NH_{4(aq)}^+ + HO^-_{(aq)}$.

**2.2.** $[HO^-] = 10^{pH}\,K_e = 3{,}98\cdot10^{-4}~\mathrm{mol\cdot L^{-1}}$.

**2.3.** Taux d'avancement final : $\tau = \dfrac{[HO^-]}{C_b} = 3{,}98\cdot10^{-2} = 3{,}98\%$.

**2.4.** $Q_{r,\text{éq}} = \dfrac{[HO^-]^2_{\text{éq}}}{C_b - [HO^-]_{\text{éq}}} = 1{,}65\cdot10^{-5}$.

**2.5.** $K_A = \dfrac{K_e}{Q_{r,\text{éq}}}$ d'où $pK_A = -\log\left(\dfrac{K_e}{Q_{r,\text{éq}}}\right) \approx 9{,}2$.

**Partie 2.** **1.** La masse de chrome diminue (oxydation, perte d'électrons) : l'**anode est l'électrode de chrome**.

**2.** Schéma conventionnel : $(+)\ Ag_{(s)}/Ag^+_{(aq)}\ //\ Cr^{3+}_{(aq)}/Cr_{(s)}\ (-)$.

**3.** Anode (oxydation) : $Cr_{(s)} \rightleftarrows Cr^{3+}_{(aq)} + 3e^-$ ; cathode (réduction) : $Ag^+_{(aq)} + e^- \rightleftarrows Ag_{(s)}$ ; bilan : $3Ag^+_{(aq)} + Cr_{(s)} \rightleftarrows 3Ag_{(s)} + Cr^{3+}_{(aq)}$.

**4.** $\Delta m(Cr) = -\dfrac{Q\,M(Cr)}{3F} = -1{,}04\cdot10^{-3}~\mathrm{g} = -1{,}04~\mathrm{mg}$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 4 <span class="font-normal text-white/80 text-sm">(5 points)</span></div>
**I.** **1.** Loi d'additivité des tensions ($E = u_L + u_R$ avec $u_L = L\dfrac{di}{dt} + r\,i$, $u_R = R\,i$) : $\dfrac{di}{dt} + \dfrac{R+r}{L}\,i = \dfrac{E}{L}$.

**2.** En régime permanent $u_L(\infty) = r\,I_0$ ; graphiquement $u_L(\infty) = 1~\mathrm{V}$ et $I_0 = 100~\mathrm{mA}$, d'où $r = \dfrac{u_L(\infty)}{I_0} = 10~\Omega$.

**3.** $\tau = \dfrac{L}{R+r}$ ; graphiquement $\tau = 0{,}01~\mathrm{s}$, donc $L = (R+r)\tau = (90+10)\times0{,}01 = 1~\mathrm{H}$.

**II.** **1.** Régime **pseudo-périodique** (l'amplitude des oscillations diminue progressivement).

**2.** Loi d'additivité ($u_L + u_R + u_C = 0$) : $\dfrac{d^2u_C}{dt^2} + \dfrac{R+r}{L}\,\dfrac{du_C}{dt} + \dfrac{1}{LC}\,u_C = 0$.

**3.** $T_0 = 2\pi\sqrt{LC}$ d'où $C = \dfrac{T_0^2}{4\pi^2 L}$ ; avec $T = T_0 = 10~\mathrm{ms}$ : $C = 2{,}5\cdot10^{-6}~\mathrm{F} = 2{,}5~\mathrm{\mu F}$.

**III.** **1.** $\dfrac{d^2u_C}{dt^2} + \dfrac{R+r-k_0}{L}\,\dfrac{du_C}{dt} + \dfrac{1}{LC}\,u_C = 0$ ; oscillations entretenues si $R+r-k_0 = 0$, d'où $k_0 = R+r = 100~\Omega$ (S.I.).

**2.** Graphiquement (figure 6) : $T_0 = 10~\mathrm{ms}$ et $I_m = 8~\mathrm{mA}$ ; conditions initiales $i(0)=0$ et $\dfrac{di}{dt}(0)<0$ donnent $\varphi = \dfrac{\pi}{2}~\mathrm{rad}$.

**3.** Quand $u_C = 0$, $i = \pm I_m$ : $E_T = \dfrac{1}{2}L\,I_m^2 = \dfrac{1}{2}\times1\times(8\cdot10^{-3})^2 = 3{,}2\cdot10^{-5}~\mathrm{J}$.

**4.** $E_{e1} = E_T - \dfrac{1}{2}L\,i_1^2$ ; graphiquement à $t_1 = 16~\mathrm{ms}$, $i_1 = 4{,}8~\mathrm{mA}$, d'où $E_{e1} \approx 2{,}05\cdot10^{-5}~\mathrm{J}$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 5 <span class="font-normal text-white/80 text-sm">(2,5 points)</span></div>
**1.** Deuxième loi de Newton ($\vec{P} + \vec{f} = m\,\vec{a}_G$) projetée sur $(O,\vec{j})$ : $m\,g - k\,v = m\dfrac{dv}{dt}$, d'où $\dfrac{dv}{dt} + \dfrac{k}{m}\,v = g$.

**2.** En régime permanent $\dfrac{dv}{dt} = 0$ : $v_\ell = \dfrac{m\,g}{k}$.

**3.** Graphiquement (figure 2) : $v_\ell = 1{,}5~\mathrm{m\cdot s^{-1}}$.

**4.** $\dfrac{k}{m} = \dfrac{g}{v_\ell} = \dfrac{10}{1{,}5} = 6{,}67$, d'où $\dfrac{dv}{dt} = 10 - 6{,}67\,v$.

**5.1.** $a_1 = 10 - 6{,}67\,v_1 = 10 - 6{,}67\times0{,}150 = 9{,}00~\mathrm{m\cdot s^{-2}}$.

**5.2.** Méthode d'Euler : $v_3 = a_2\,\Delta t + v_2 = 8{,}10\times0{,}015 + 0{,}285 \approx 0{,}406~\mathrm{m\cdot s^{-1}}$.

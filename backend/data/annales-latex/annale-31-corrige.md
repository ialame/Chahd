<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 1 <span class="font-normal text-white/80 text-sm">(7 points)</span></div>
**Partie 1.** **1.** L'électrode **B**, reliée au pôle $\oplus$ du générateur, cède des électrons à la solution : il s'y produit l'oxydation, c'est l'**anode**.

**2.** À la cathode (électrode A) : $Zn^{2+}_{(aq)} + 2e^- \longrightarrow Zn_{(s)}$ (réduction) ; à l'anode (électrode B) : $2I^-_{(aq)} \longrightarrow I_{2(g)} + 2e^-$ (oxydation). Équation bilan : $Zn^{2+}_{(aq)} + 2I^-_{(aq)} \longrightarrow Zn_{(s)} + I_{2(g)}$.

**3.** $\Delta t = \dfrac{2\,m\,F}{I\,M(Zn)} \Rightarrow \Delta t = 157{,}4~\mathrm{min}$.

**Partie 2.** **1.** $C_6H_5COOH_{(aq)} + H_2O_{(l)} \rightleftharpoons C_6H_5COO^-_{(aq)} + H_3O^+_{(aq)}$.

**2.** Tableau d'avancement : état initial $n_i = C\cdot V$ (eau en excès), produits nuls ; à l'équilibre $[C_6H_5COO^-]_{eq} = [H_3O^+]_{eq} = \dfrac{x_{eq}}{V}$.

**3.1.** $\sigma = [H_3O^+]_{eq}\,(\lambda_1 + \lambda_2)$.

**3.2.** $\tau = \dfrac{\sigma}{C\,(\lambda_1 + \lambda_2)} \Rightarrow \tau = 0{,}22 = 22\,\%$.

**4.** $K = \dfrac{\tau^{2}\,C}{1 - \tau}$.

**5.** $K$ représente la **constante d'acidité** $K_A$ du couple acide-base $C_6H_5COOH/C_6H_5COO^-$.

**6.** $pK_A = -\log\!\left(\dfrac{\tau^{2}\,C}{1 - \tau}\right) \Rightarrow pK_A = 4{,}2$.

**7.** $pH = -\log(\tau\,C\,V) = 3{,}66$. Puisque $pH = 3{,}66 < pK_A = 4{,}2$, l'espèce prédominante dans $S$ est l'acide $C_6H_5COOH$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 2 <span class="font-normal text-white/80 text-sm">(3,5 points)</span></div>
**Partie 1.** **1.** L'onde est **transversale** : la direction de la perturbation est perpendiculaire à celle de la propagation.

**2.** $\lambda = 1{,}5~\mathrm{cm}$.

**3.** $v = \lambda\,N = 1{,}5\cdot10^{-2}\times20 \Rightarrow v = 0{,}3~\mathrm{m\cdot s^{-1}}$.

**4.** $\tau = \dfrac{SM}{v} = \dfrac{2\lambda}{\lambda}\,T = 2T = \dfrac{2}{N} \Rightarrow \tau = 0{,}1~\mathrm{s}$.

**Partie 2.** **1.** Puisque $\xi(^{218}_{84}\mathrm{Po}) = 7{,}73 > \xi(^{222}_{86}\mathrm{Rn}) = 7{,}69~\mathrm{MeV/nucléon}$, le noyau $^{218}_{84}\mathrm{Po}$ est le plus stable.

**2.** $E_\ell(^{4}_{2}\mathrm{He}) = A\,\xi(^{4}_{2}\mathrm{He}) = 4\times7{,}07 \Rightarrow E_\ell(\mathrm{He}) = 28{,}28~\mathrm{MeV}$.

**3.** Réponse **C** : $E_{lib} = |222\times7{,}69 - (88\times7{,}73 - 28{,}28)| \Rightarrow E_{lib} = 6{,}24~\mathrm{MeV}$.

**4.** $e^{-\lambda t_1} = \dfrac{1}{4} \Rightarrow t_1 = 2\,t_{1/2} = 2\times3{,}8 \Rightarrow t_1 = 7{,}6~\text{jours}$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 3 <span class="font-normal text-white/80 text-sm">(4,5 points)</span></div>
**I.** **1.** Loi d'additivité des tensions $u_R + u_C = E$, avec $u_R = R\,i$, $i = \dfrac{dq}{dt}$ et $u_C = \dfrac{q}{C}$ : $RC\,\dfrac{dq}{dt} + q = C\,E$.

**2.** En reportant $q(t) = A\,(1 - e^{-\alpha t})$ : $\alpha = \dfrac{1}{RC}$ et $A = C\,E$.

**3.1.** $Q = q_{max} = 100~\mathrm{\mu C}$. **3.2.** $\tau = 1~\mathrm{ms}$.

**4.** En régime permanent $\dfrac{dq}{dt} = 0$ d'où $Q = C\,E \Rightarrow C = \dfrac{Q}{E} = \dfrac{100\cdot10^{-6}}{10} \Rightarrow C = 10~\mathrm{\mu F}$.

**5.** $\tau = R\,C \Rightarrow R = \dfrac{\tau}{C} = \dfrac{1\cdot10^{-3}}{10^{-5}} \Rightarrow R = 100~\Omega$.

**II.** **1.** Loi d'additivité $u_L + u_C = 0$ avec $u_L = L\,\dfrac{di}{dt}$ et $i = C\,\dfrac{du_C}{dt}$ : $\dfrac{d^{2}u_C}{dt^{2}} + \dfrac{1}{LC}\,u_C = 0$.

**2.1.** C'est la courbe **(b)** : le régime est périodique (circuit LC idéal) et $u_C(0) = E = 10~\mathrm{V}$.

**2.2.** $T_0 = 20~\mathrm{ms}$.

**3.** $T_0 = 2\pi\sqrt{LC} \Rightarrow L = \dfrac{T_0^{2}}{4\pi^{2}\,C} = \dfrac{(20\cdot10^{-3})^{2}}{4\times10\times10\cdot10^{-6}} \Rightarrow L = 1~\mathrm{H}$.

**4.1.** $E_t = \dfrac{1}{2}C\,E^{2} = \dfrac{1}{2}\times10^{-5}\times10^{2} \Rightarrow E_t = 5\cdot10^{-4}~\mathrm{J}$.

**4.2.** À $t_1$ ($u_C = -8~\mathrm{V}$) : $E_{ml} = E_t - \dfrac{1}{2}C\,u_C^{2} = 5\cdot10^{-4} - \dfrac{1}{2}\times10^{-5}\times(-8)^{2} \Rightarrow E_{ml} = 1{,}8\cdot10^{-4}~\mathrm{J}$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 4 <span class="font-normal text-white/80 text-sm">(5 points)</span></div>
**I.** **1.** $\vec{P} + \vec{R} + \vec{F} = m\,\vec{a_G}$, projection sur $(A,\vec{i})$ : $m\,g\sin\beta + F = m\,a_G \Rightarrow a_G = \dfrac{F}{m} + g\sin\beta$.

**2.** La courbe $V_G = f(t)$ est linéaire : $a_G = \dfrac{\Delta V_G}{\Delta t} = \dfrac{9 - 0}{2 - 0} \Rightarrow a_G = 4{,}5~\mathrm{m\cdot s^{-2}}$.

**3.** $F = m\,(a_G - g\sin\beta) = 190\times(4{,}5 - 10\sin10^\circ) \Rightarrow F = 525{,}07~\mathrm{N}$.

**4.** Mouvement rectiligne uniformément varié : $x(t) = \dfrac{1}{2}a_G\,t^{2} \Rightarrow x(t) = 2{,}25\,t^{2}$.

**5.** $x(t_B) = AB \Rightarrow t_B = \sqrt{\dfrac{36}{2{,}25}} \Rightarrow t_B = 4~\mathrm{s}$.

**6.** $V_B = 4{,}5\,t_B = 4{,}5\times4 \Rightarrow V_B = 18~\mathrm{m\cdot s^{-1}}$.

**II.** **1.** $\vec{P} = m\,\vec{a_G}$ : projection sur $\vec{i_1}$ donne $a_x = 0 \Rightarrow \dfrac{dx_G}{dt} = V_C\cos\alpha$ ; sur $\vec{j_1}$, $a_y = -g \Rightarrow \dfrac{dy_G}{dt} = -g\,t + V_C\sin\alpha$.

**2.** $x_G(t) = (V_C\cos\alpha)\,t$ ; identification avec $x_G = 19{,}02\,t$ donne $V_C = \dfrac{19{,}02}{\cos18^\circ} \Rightarrow V_C = 20~\mathrm{m\cdot s^{-1}}$.

**3.1.** Au point $P$ ($y_P = 0$) : $t_P = 1{,}236~\mathrm{s}$ d'où $x_P = 19{,}02\times1{,}236 = 23{,}51~\mathrm{m}$. Comme $x_P = 23{,}51~\mathrm{m} < 30~\mathrm{m}$, le saut n'est pas réussi.

**3.2.** $V_{min} = \sqrt{\dfrac{g\,x_P}{\sin(2\alpha)}} = \sqrt{\dfrac{10\times30}{\sin(2\times18^\circ)}} \Rightarrow V_{min} = 22{,}59~\mathrm{m\cdot s^{-1}}$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 1 <span class="font-normal text-white/80 text-sm">(7 points)</span></div>
**Partie 1 — I.** **1.** Équation : $CH_3COO^-_{(aq)} + H_2O_{(l)} \rightleftharpoons CH_3COOH_{(aq)} + HO^-_{(aq)}$.

**2.** $[HO^-] = K_e\cdot10^{pH} = 10^{-14}\times10^{7,9} = 7{,}94\cdot10^{-7}~\mathrm{mol\cdot L^{-1}}$.

**3.** Taux d'avancement final : $\tau = \dfrac{[HO^-]_{\text{éq}}}{C} = 7{,}94\cdot10^{-4}$. Comme $\tau < 1$, la réaction est **limitée**.

**4.** $Q_{r,\text{éq}} = \dfrac{C\,\tau^{2}}{1-\tau} = 6{,}31\cdot10^{-10}$.

**5.** $pK_{A1} = -\log\!\left(\dfrac{K_e}{Q_{r,\text{éq}}}\right) = 4{,}8$ (vérifié).

**Partie 1 — II.** **1.** Équation : $HCOOH_{(aq)} + CH_3COO^-_{(aq)} \rightleftharpoons HCOO^-_{(aq)} + CH_3COOH_{(aq)}$.

**2.** $K = 10^{\,pK_{A1}-pK_{A2}} = 10^{\,4,8-3,8} = 10$.

**3.** $Q_{r,i} = \dfrac{C_3\cdot C_4}{C_1\cdot C_2} = 1$.

**4.** $Q_{r,i} = 1 < K = 10$ : la réaction évolue spontanément dans le **sens direct** (formation de $CH_3COOH$ et $HCOO^-$).

**5.** $pH = \log\!\left(\dfrac{C_4 V_4 + x_{\text{éq}}}{C_1 V_1 - x_{\text{éq}}}\right) = 4{,}27$.

**Partie 2.** **1.** Schéma conventionnel : $\ominus\ Al_{(s)}/Al^{3+}_{(aq)}\ //\ Zn^{2+}_{(aq)}/Zn_{(s)}\ \oplus$.

**2.** Anode (oxydation) : $2\times\left(Al_{(s)} \rightleftharpoons Al^{3+}_{(aq)} + 3e^-\right)$ ; cathode (réduction) : $3\times\left(Zn^{2+}_{(aq)} + 2e^- \rightleftharpoons Zn_{(s)}\right)$ ; bilan : $2Al_{(s)} + 3Zn^{2+}_{(aq)} \longrightarrow 2Al^{3+}_{(aq)} + 3Zn_{(s)}$.

**3.** $[Zn^{2+}] = [Zn^{2+}]_i - \dfrac{I\,\Delta t}{2F\,V_2} = 8{,}7\cdot10^{-2}~\mathrm{mol\cdot L^{-1}}$.

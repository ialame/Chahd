<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 1 <span class="font-normal text-white/80 text-sm">(7 points)</span></div>
**Partie 1.** **1.** Schéma : la **plaque de cuivre est la cathode** (dépôt d'or, réduction), l'**électrode de graphite est l'anode** (dégagement de $Cl_2$, oxydation) ; dans le circuit extérieur le courant circule du pôle $+$ vers l'anode.

**2.** À la cathode : $\left(Au^{3+}_{(aq)} + 3e^- \rightleftharpoons Au_{(s)}\right)\times 2$ ; à l'anode : $\left(2Cl^-_{(aq)} \rightleftharpoons Cl_{2(g)} + 2e^-\right)\times 3$. Équation bilan : $2Au^{3+}_{(aq)} + 6Cl^-_{(aq)} \rightleftharpoons 2Au_{(s)} + 3Cl_{2(g)}$.

**3.** $\Delta t = \dfrac{3F\,m}{I\,M(Au)} = \dfrac{3\times 9{,}65\cdot10^{4}\times 0{,}031}{50\cdot10^{-3}\times 197} = 911{,}12~\mathrm{s} \simeq 15{,}2~\mathrm{min}$.

**Partie 2.** **1.1.** Une **base** selon Brönsted est toute espèce chimique capable de **capter au moins un proton $H^+$** au cours d'une transformation chimique.

**1.2.** $CH_3-NH_{2(aq)} + H_2O_{(l)} \rightleftharpoons CH_3-NH^+_{3(aq)} + HO^-_{(aq)}$.

**1.3.** $\tau = \dfrac{10^{pH}\,K_e}{C_b} = \dfrac{10^{11{,}3}\times 10^{-14}}{10^{-2}} = 0{,}1995 \simeq 0{,}2$, soit $\tau \simeq 20\,\%$. Comme $\tau < 1$, la transformation est **limitée**.

**1.4.** $Q_{r,\text{éq}} = \dfrac{C_b\cdot\tau^{2}}{1-\tau} = \dfrac{10^{-2}\times(0{,}2)^2}{1-0{,}2} = 5\cdot10^{-4}$.

**1.5.** $K_A = \dfrac{K_e}{Q_{r,\text{éq}}}$ d'où $pK_A = -\log\!\left(\dfrac{K_e}{Q_{r,\text{éq}}}\right) = -\log\!\left(\dfrac{10^{-14}}{5\cdot10^{-4}}\right) = 10{,}699 \simeq 10{,}7$.

**2.1.** $CH_3-NH_{2(aq)} + H_3O^+_{(aq)} \longrightarrow CH_3-NH^+_{3(aq)} + H_2O_{(l)}$.

**2.2.** Coordonnées d'équivalence : $V_{aE} = 15~\mathrm{mL}$ ; $pH_E = 6{,}6$.

**2.3.** $C_b = \dfrac{C_a\,V_{aE}}{V_b} = \dfrac{10^{-2}\times 15\cdot10^{-3}}{15\cdot10^{-3}} = 10^{-2}~\mathrm{mol\cdot L^{-1}}$.

**2.4.** Indicateur adéquat : le **bleu de bromothymol** car sa zone de virage contient $pH_E$ : $6{,}0 \leqslant pH_E = 6{,}6 \leqslant 7{,}6$.

**2.5.** $\dfrac{[CH_3-NH_{2(aq)}]}{[CH_3-NH^+_{3(aq)}]} = 10^{pH-pK_A} = 10^{2{,}8-10{,}7} = 1{,}26\cdot10^{-8} \ll 1$ : l'espèce prédominante est l'acide $CH_3-NH^+_{3(aq)}$.

**3.** $t_1 = \dfrac{t_{1/2}}{\ln 2}\,\ln\!\left(\dfrac{a_0}{a_1}\right) = \dfrac{5730}{\ln 2}\,\ln\!\left(\dfrac{418}{318}\right) = 2260{,}35~\text{ans}$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 3 <span class="font-normal text-white/80 text-sm">(4,5 points)</span></div>
**1.1.** Visualisation de $u_R(t)$ : voir figure 1 (branchement du système d'acquisition aux bornes de $R$, comme un oscilloscope).

**1.2.** Loi d'additivité des tensions $u_L + u_R = E$, avec $u_L = L_0\dfrac{di}{dt} + r\,i$ et $u_R = R\,i$, donne : $\dfrac{du_R}{dt} + \dfrac{R+r}{L_0}\,u_R = \dfrac{E\,R}{L_0}$.

**1.3.** En régime permanent : $U_0 = 9{,}8~\mathrm{V}$.

**1.4.** $I_0 = \dfrac{U_0}{R} = \dfrac{9{,}8}{490} = 0{,}2~\mathrm{A}$ ; $(R+r)I_0 = E \Rightarrow r = \dfrac{E}{I_0} - R = \dfrac{10}{0{,}2} - 490 = 10~\Omega$.

**1.5.** $L_0 = \tau\,(R+r)$ avec $\tau = 1~\mathrm{ms}$ : $L_0 = 10^{-3}\times(490+10) = 0{,}5~\mathrm{H}$.

**1.6.** La courbe représentant $u_R(t)$ pour $L = L_1 = 2L_0$ est la courbe **$C_2$** : elle tend vers la même valeur permanente $U_0 = 9{,}8~\mathrm{V}$ (ce qui élimine $C_4$ dont $U_0 = 12~\mathrm{V}$) et sa constante de temps $\tau_1 = 2\tau$ est la **plus grande**.

**2.1.** Loi d'additivité $u_L + u_C = 0$, avec $u_C = \dfrac{q}{C}$ et $i = \dfrac{dq}{dt}$ : $\dfrac{d^{2}q}{dt^{2}} + \dfrac{r}{L}\,\dfrac{dq}{dt} + \dfrac{1}{L\,C}\,q = 0$.

**2.2.** $T_0 = 2\pi\sqrt{L\,C} \Rightarrow C = \dfrac{T_0^{2}}{4\pi^{2}L}$ ; avec $T_0 = 0{,}10~\mathrm{s}$ : $C = \dfrac{(0{,}10)^2}{4\times 10\times 1} = 2{,}5\cdot10^{-4}~\mathrm{F} = 250~\mathrm{\mu F}$.

**3.1.** Partie 1 : **réception et sélection** de l'onde modulée. Partie 3 (avec $C_2$ et $R_2$) : **élimination de la composante continue** (détection d'enveloppe).

**3.2.** $L = \dfrac{1}{4\pi^{2}C_1\,f_0^{2}} = \dfrac{1}{4\times 10\times 85{,}4\cdot10^{-12}\times(171\cdot10^{3})^2} = 0{,}01~\mathrm{H} = 10~\mathrm{mH}$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 4 <span class="font-normal text-white/80 text-sm">(5 points)</span></div>
**Partie 1.** **1.1.** Deuxième loi de Newton $\vec{P} + \vec{R} + \vec{F} = m\,\vec{a}_G$ projetée sur $(O,\vec{i})$ : $-m\,g\sin\alpha - f + F = m\,\dfrac{d^{2}x}{dt^{2}}$, d'où $\dfrac{d^{2}x}{dt^{2}} = \dfrac{F-f}{m} - g\sin\alpha$.

**1.2.1.** La courbe $x = f(t^2)$ est linéaire, $x = K\,t^2$ avec $K = 1~\mathrm{m\cdot s^{-2}}$ ; donc $a_{1x} = 2K = 2~\mathrm{m\cdot s^{-2}}$.

**1.2.2.** $F = m\,(a_{1x} + g\sin\alpha) + f = 2\times(2 + 10\sin 17{,}5^\circ) + 2 \simeq 12~\mathrm{N}$.

**1.2.3.** $V_A = \sqrt{2\,OA\,a_{1x}} = \sqrt{2\times 4\times 2} = 4~\mathrm{m\cdot s^{-1}}$.

**2.1.** Avec $F = 0$ : $a_{2x} = -\dfrac{f}{m} - g\sin\alpha = -\dfrac{2}{2} - 10\sin 17{,}5^\circ = -4~\mathrm{m\cdot s^{-2}}$.

**2.2.** $v_B = 0 \Rightarrow t_B = -\dfrac{V_A}{a_{2x}} = 1~\mathrm{s}$ ; $AB = \dfrac{1}{2}a_{2x}\,t_B^{2} + V_A\,t_B = \dfrac{1}{2}(-4)(1)^2 + 4\times 1 = 2~\mathrm{m}$.

**Partie 2.** **1.** Nature du mouvement : **rectiligne oscillatoire sinusoïdal**.

**2.** Deuxième loi de Newton $\vec{P} + \vec{R} + \vec{T} = m\,\vec{a}_G$ projetée sur $(O,\vec{i})$ : $-k\,x = m\,\dfrac{d^{2}x}{dt^{2}}$, d'où $\ddot{x} + \dfrac{k}{m}\,x = 0$.

**3.** $T_0 = 2\pi\sqrt{\dfrac{m}{k}} \Rightarrow k = \dfrac{4\pi^{2}m}{T_0^{2}}$ ; avec $T_0 = 1~\mathrm{s}$ : $k = \dfrac{4\times 10\times 0{,}5}{1^{2}} = 20~\mathrm{N\cdot m^{-1}}$.

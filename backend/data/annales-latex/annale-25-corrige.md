**Partie 1.** **1.** La réduction de l'ion chrome (III) se fait au niveau de la cathode : la **plaque d'acier joue le rôle de la cathode**.

**2.1.** Réponse **A** : $2H_2O_{(l)} \rightleftarrows O_{2(g)} + 4H^+_{(aq)} + 4e^-$.

**2.2.** Réponse **B** : $Cr^{3+}_{(aq)} + 3e^- \rightleftarrows Cr_{(s)}$.

**3.** $m(Cr) = \dfrac{I\,\Delta t\,M(Cr)}{3F} = \dfrac{2\times2\times3600\times52}{3\times96500}$, soit $m(Cr) = 2{,}59~\mathrm{g}$.

**Partie 2.** **1.1.** $C_2H_5COOH_{(aq)} + H_2O_{(l)} \rightleftarrows C_2H_5COO^-_{(aq)} + H_3O^+_{(aq)}$.

**1.2.** $\tau = \dfrac{10^{-pH}}{C_a} = \dfrac{10^{-3{,}1}}{5\cdot10^{-2}} = 0{,}0159$, soit $\tau \simeq 1{,}6\,\%$. Comme $\tau < 1$, la réaction est **limitée**.

**1.3.** $Q_{r,\mathrm{eq}} = \dfrac{\left[H_3O^+\right]_{\mathrm{eq}}^2}{C_a - \left[H_3O^+\right]_{\mathrm{eq}}}$, soit $Q_{r,\mathrm{eq}} = 1{,}28\cdot10^{-5}$.

**1.4.** $pK_A = -\log Q_{r,\mathrm{eq}} = -\log(1{,}28\cdot10^{-5})$, soit $pK_A \approx 4{,}9$.

**2.1.** $C_2H_5COOH_{(aq)} + HO^-_{(aq)} \rightleftarrows C_2H_5COO^-_{(aq)} + H_2O_{(l)}$.

**2.2.** Volume à l'équivalence : $V_{bE} = 20~\mathrm{mL}$.

**2.3.** $C_a = \dfrac{C_b\,V_{bE}}{V_a} = 5\cdot10^{-2}~\mathrm{mol\cdot L^{-1}}$ (valeur vérifiée).

**2.4.** $m = 10\,C_a\,M\,V = 10\times5\cdot10^{-2}\times74\times1$, soit $m = 37~\mathrm{g}$.

**2.5.** Pour $V_b = 5~\mathrm{mL}$ ($pH = 4{,}4$) : $\%(C_2H_5COOH) = \dfrac{1}{1 + 10^{pH - pK_A}} \simeq 76\,\%$.

**Partie 1.** **1.1.** L'onde sonore est une onde transversale : **Faux**.

**1.2.** L'onde sonore ne se propage pas dans le vide : **Vrai**.

**2.** $\Delta t = 5\times0{,}5~\mathrm{ms} = 2{,}5~\mathrm{ms}$.

**3.** $v = \dfrac{L}{\Delta t} = \dfrac{85\cdot10^{-2}}{2{,}5\cdot10^{-3}}$, soit $v = 340~\mathrm{m\cdot s^{-1}}$.

**Partie 2.** **1.** Loi de Soddy $\Rightarrow A = 131$, $Z = 54$ : le noyau produit est le xénon. $^{131}_{53}\mathrm{I} \longrightarrow\ ^{131}_{54}\mathrm{Xe} + \ ^{\;0}_{-1}\mathrm{e}$.

**2.** $\Delta E = \left[m(^{131}_{54}\mathrm{Xe}) + m(\beta^-) - m(^{131}_{53}\mathrm{I})\right]c^2$, soit $|\Delta E| \simeq 0{,}46055~\mathrm{MeV}$.

**3.1.** Demi-vie : $t_{1/2} = 8~\text{jours}$.

**3.2.** $N_0 = \dfrac{a_0\,t_{1/2}}{\ln 2} = \dfrac{4\cdot10^6\times8\times24\times3600}{\ln 2}$, soit $N_0 \simeq 3{,}99\cdot10^{12}$ noyaux.

**3.3.** $t_1 = -\dfrac{t_{1/2}}{\ln 2}\ln(0{,}05) = -\dfrac{8}{\ln 2}\ln(0{,}05)$, soit $t_1 \simeq 34{,}575~\text{jours}$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 3 <span class="font-normal text-white/80 text-sm">(4,5 points)</span></div>
**1.1.** Loi des mailles $u_R + u_C = E$ avec $u_R = R\,i = RC\dfrac{du_C}{dt}$ : $\dfrac{du_C}{dt} + \dfrac{1}{RC}\,u_C = \dfrac{E}{RC}$.

**1.2.1.** $i(t) = C\dfrac{du_C}{dt} = \dfrac{E}{R}\,e^{-\frac{t}{RC}}$.

**1.2.2.** $R = \dfrac{E}{i(0)} = \dfrac{12}{12\cdot10^{-3}} = 10^3~\Omega$, soit $R = 1~\mathrm{k\Omega}$.

**1.2.3.** $\tau = RC = 50~\mathrm{ms} \Rightarrow C = \dfrac{\tau}{R} = \dfrac{50\cdot10^{-3}}{10^3} = 50~\mathrm{\mu F}$.

**2.1.1.** $u_L + u_C = 0$ avec $u_L = L\dfrac{di}{dt}$ et $i = C\dfrac{du_C}{dt}$ : $\dfrac{d^2u_C}{dt^2} + \dfrac{1}{LC}\,u_C = 0$.

**2.1.2.** Circuit idéal $LC$ : oscillations libres périodiques d'amplitude constante avec $u_C(0) = E = 12~\mathrm{V}$ : c'est la courbe **$(C_1)$**.

**2.1.3.a.** $T_0 = 2\pi\sqrt{LC}$.

**2.1.3.b.** $L = \dfrac{T_0^2}{4\pi^2 C} = \dfrac{(10\cdot10^{-3})^2}{4\times10\times50\cdot10^{-6}}$, soit $L = 0{,}05~\mathrm{H}$.

**2.2.1.** $E_t = \dfrac{1}{2}C\,u_C^2(t) + \dfrac{1}{2}L\,i^2(t)$.

**2.2.2.** $E_0 = 3{,}6\cdot10^{-3}~\mathrm{J}$ (à $t_0$) et $E_1 = 1{,}39\cdot10^{-3}~\mathrm{J}$ (à $t_1$) : $\Delta E = E_1 - E_0 \simeq -2{,}21~\mathrm{mJ}$.

**Partie 2.** **1.1.** Réponse **B** : $F_{T/S} = G\dfrac{M_T\,m_s}{(R_T + h_1)^2}$.

**1.2.** 2ᵉ loi de Newton dans le repère de Frenet : $\dfrac{G\,M_T}{(R_T + h_1)^2} = \dfrac{v^2}{R_T + h_1} \Rightarrow v = \sqrt{\dfrac{G\,M_T}{R_T + h_1}}$.

**2.4.** $v_1 = -\dfrac{1}{160\,V_0}\left(\dfrac{\Delta\sigma}{\Delta t}\right)_{t_1} = 0{,}781~\mathrm{mol\cdot m^{-3}\cdot min^{-1}}$.

**Partie 2.** **1.1.** Équation du dosage : $AH_{(aq)} + HO^-_{(aq)} \longrightarrow A^-_{(aq)} + H_2O_{(l)}$.

**2.3.** Propriété mise en évidence : la **dispersion** de la lumière (la célérité dépend de la fréquence dans le prisme).

**3.1.** $\theta = \dfrac{L}{2D}$ et $\theta = \dfrac{\lambda}{a}$ d'où $L = \dfrac{2\lambda D}{a}$.

**3.2.** Coefficient directeur $K = \dfrac{\Delta L}{\Delta D} = 2\cdot10^{-2}$ ; $\lambda = \dfrac{a\,K}{2} = 6\cdot10^{-7}~\mathrm{m} = 600~\mathrm{nm}$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 4 <span class="font-normal text-white/80 text-sm">(4,75 points)</span></div>
**I. 1.** Équation différentielle : $\dfrac{du_C}{dt} = -\dfrac{1}{RC}\,u_C + \dfrac{E}{RC}$.

**I. 2.** Coefficient directeur $a = \dfrac{\Delta(du_C/dt)}{\Delta u_C} = -83{,}3~\mathrm{s^{-1}} = -\dfrac{1}{RC}$ d'où $C = 1{,}2\cdot10^{-5}~\mathrm{F} = 12~\mathrm{\mu F}$.

**II. 1.** Régime mis en évidence : **régime périodique**.

**II. 2.** Équation différentielle : $\dfrac{d^2q}{dt^2} + \dfrac{1}{LC}\,q = 0$.

**II. 3.** $T_0 = 2\pi\sqrt{LC}$.

**II. 4.** Lecture graphique : $T_0 = 21~\mathrm{ms}$.

**II. 5.** $L = \dfrac{T_0^2}{4\pi^2 C} \simeq 0{,}92~\mathrm{H}$.

**III. 1.** La modulation d'amplitude consiste à faire varier l'amplitude d'un signal de fréquence élevée (signal porteur) en fonction d'un signal de basse fréquence (signal modulant).

**III. 2.1.** $F_p = \dfrac{1}{T_p} = 1500~\mathrm{Hz}$ ; $f_s = \dfrac{1}{T_s} = 125~\mathrm{Hz}$.

**III. 2.2.** $S_m = 0{,}5~\mathrm{V}$ ; $U_0 = 1{,}5~\mathrm{V}$.

**III. 3.** Taux de modulation $\tau = \dfrac{S_m}{U_0} = 0{,}33 < 1$ et $F_p \geq 10\,f_s$ : la modulation est **de bonne qualité**.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 5 <span class="font-normal text-white/80 text-sm">(2,75 points)</span></div>
**1.1.** La trajectoire est rectiligne et $v = a\,t$ (linéaire, $a = \text{cte}$) : le mouvement de $G$ est **rectiligne uniformément varié**.

**1.2.** Coefficient directeur $a = \dfrac{\Delta v}{\Delta t} = 10~\mathrm{m\cdot s^{-2}} = g$ : le mouvement est bien une **chute libre**.

**2.1.** Équation différentielle : $\dfrac{dv}{dt} + \dfrac{\alpha}{m}\,v^2 = g$.

**2.2.** En régime permanent $\dfrac{dv}{dt} = 0$ d'où $V_\ell = \sqrt{\dfrac{g\,m}{\alpha}}$.

**2.3.** Lecture graphique : $V_\ell = 5~\mathrm{m\cdot s^{-1}}$.

**2.4.** $\alpha = \dfrac{g\,m}{V_\ell^2} = \dfrac{10\times100}{5^2} = 40~\mathrm{kg\cdot m^{-1}}$.

**3.** $d_1 = \dfrac{1}{2}g\,\Delta t_1^2 = 80~\mathrm{m}$ ; $d' = V_\ell\,\Delta t' = 5\times36 = 180~\mathrm{m}$ ; d'où $d = h - d_1 - d' = 660 - 80 - 180 = 400~\mathrm{m}$.

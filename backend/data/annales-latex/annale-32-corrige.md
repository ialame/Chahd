<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 1 <span class="font-normal text-white/80 text-sm">(7 points)</span></div>
**Partie 1 — Pile nickel-cadmium.** **1.** Quotient de réaction initial : $Q_{r,i} = \dfrac{[Cd^{2+}]_i}{[Ni^{2+}]_i} = \dfrac{C}{C} = 1$. Comme $Q_{r,i} < K = 4{,}5\cdot10^{5}$, le système évolue **spontanément dans le sens direct** (formation de $Ni$ et $Cd^{2+}$).

**2.** Schéma conventionnel : $\oplus\ Ni_{(s)}/Ni^{2+}_{(aq)}\ \|\ Cd^{2+}_{(aq)}/Cd_{(s)}\ \ominus$.

**3.** À la cathode (nickel, réduction) : $Ni^{2+}_{(aq)} + 2e^- \rightleftharpoons Ni_{(s)}$ ; à l'anode (cadmium, oxydation) : $Cd_{(s)} \rightleftharpoons Cd^{2+}_{(aq)} + 2e^-$.

**4.** Variation de masse du nickel : $\Delta m = \dfrac{I\cdot\Delta t}{2F}\,M(Ni) = \dfrac{0{,}3\times5\times3600}{2\times9{,}65\cdot10^{4}}\times58{,}7 \simeq 1{,}64~\mathrm{g}$.

**Partie 2 — Acide acétylsalicylique.** **I-1.** Équation du dosage : $AH_{(aq)} + HO^-_{(aq)} \longrightarrow A^-_{(aq)} + H_2O_{(l)}$.

**I-2.1.** Concentration : $C_A = \dfrac{C_B\cdot V_{BE}}{V_A} = \dfrac{10^{-2}\times10}{10} = 10^{-2}~\mathrm{mol\cdot L^{-1}}$.

**I-2.2.** Masse : $m = C_A\,M(C_9H_8O_4)\,V = 10^{-2}\times180\times278\cdot10^{-3} = 0{,}5~\mathrm{g}$.

**I-3.** Le mélange à l'équivalence est basique ($pH_E > 7$) ; l'indicateur convenable est le **rouge de crésol** (zone de virage $7{,}2 - 8{,}8$).

**II-1.** Quantités initiales : $n_0(C_9H_8O_4) = \dfrac{m}{M} = \dfrac{0{,}5}{180} \simeq 2{,}8~\mathrm{mmol}$ ; $n_0(HCO_3^-) = C\cdot V = 0{,}5\times10\cdot10^{-3} = 5~\mathrm{mmol}$.

**II-3.** Avancement maximal : $C_9H_8O_4$ est le réactif limitant, $x_{max} = 2{,}8~\mathrm{mmol}$.

**II-4.** Vitesse volumique à $t = 100~\mathrm{s}$ : $v(t) = \dfrac{1}{V}\left(\dfrac{\Delta x}{\Delta t}\right)_t = \dfrac{1}{10\cdot10^{-3}}\cdot\dfrac{1{,}5 - 0{,}75}{75 - 0} = 1~\mathrm{mmol\cdot L^{-1}\cdot s^{-1}} = 10^{-3}~\mathrm{mol\cdot L^{-1}\cdot s^{-1}}$.

**II-5.** Temps de demi-réaction : $x(t_{1/2}) = \dfrac{x_{max}}{2} = 1{,}4~\mathrm{mmol}$ donne graphiquement $t_{1/2} = 70~\mathrm{s}$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 2 <span class="font-normal text-white/80 text-sm">(2,5 points)</span></div>
**1.** L'analyse dimensionnelle donne $[\lambda] = \dfrac{[a]\,[L]}{[D]} = [L]$ ; l'expression juste est $\lambda = \dfrac{a\cdot L}{2D}$.

**2.1.** L'écart angulaire $\theta = \dfrac{\lambda}{a}$ augmente si $\lambda$ augmente : **vrai**.

**2.2.** $L = \dfrac{2\lambda D}{a}$ : $L$ est **inversement** proportionnelle à $a$ : **faux**.

**3.** Longueur d'onde : $\lambda_R = \dfrac{a\cdot L_R}{2D} = \dfrac{0{,}3\cdot10^{-3}\times8{,}5\cdot10^{-3}}{2\times2} = 6{,}375\cdot10^{-7}~\mathrm{m} \Rightarrow \lambda_R = 637{,}5~\mathrm{nm}$.

**4.** Comme $\lambda \propto L$ et $\lambda_R > \lambda_B$, on a $L_R > L_B$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 3 <span class="font-normal text-white/80 text-sm">(5 points)</span></div>
**Partie 1 — Dipôle RL.** **1.** À $t=0$, $i(0)=0$ donc $u_R(0)=R\,i(0)=0$ : la courbe $u_R(t)$ passe par l'origine, c'est la **courbe (2)**.

**2.** Équation différentielle : $\dfrac{du_R}{dt} + \dfrac{R+r}{L}\,u_R = \dfrac{R\,E}{L}$.

**3.** En régime permanent : $U_R = \dfrac{R\,E}{R+r}$.

**4.** Résistance de la bobine : avec $U_R = 8~\mathrm{V}$, $r = R\left(\dfrac{E}{U_R} - 1\right) = 40\times\left(\dfrac{10}{8} - 1\right) = 10~\Omega$.

**5.** Constante de temps (graphiquement) : $\tau = 0{,}01~\mathrm{s}$.

**6.** Vérification : $\tau = \dfrac{L}{R+r} \Rightarrow L = \tau(R+r) = 0{,}01\times(40+10) = 0{,}5~\mathrm{H}$.

**Partie 1 — Circuit RLC série.** **1.** Les courbes de la figure 4 correspondent au **régime pseudopériodique**.

**2.** Avec $T \approx T_0 = 2\pi\sqrt{L\,C}$ et $T = 10~\mathrm{ms}$ : $C = \dfrac{T_0^2}{4\pi^2 L} = \dfrac{(10\cdot10^{-3})^2}{4\times10\times0{,}5} = 5\cdot10^{-6}~\mathrm{F} = 5~\mathrm{\mu F}$.

**3.** Énergie totale à $t_1 = 9~\mathrm{ms}$ (avec $u_{C1} = 4{,}8~\mathrm{V}$ et $i_1 = 12~\mathrm{mA}$) : $E_{t_1} = \dfrac{1}{2}C\,u_{C1}^2 + \dfrac{1}{2}L\,i_1^2 = \dfrac{1}{2}\times5\cdot10^{-6}\times4{,}8^2 + \dfrac{1}{2}\times0{,}5\times(12\cdot10^{-3})^2 \simeq 9{,}36\cdot10^{-5}~\mathrm{J}$.

**Partie 2 — Modulation d'amplitude.** **1.** Fréquence porteuse $F_p = f_2 = 3\cdot10^{5}~\mathrm{Hz}$ ; fréquence modulante $f_m = f_1 = 10^{4}~\mathrm{Hz}$.

**2.** Taux de modulation : $m = \dfrac{U_1}{U_0} = \dfrac{0{,}6}{0{,}8} = 0{,}75$.

**3.** Modulation **bonne** : $m < 1$ et $F_p > 10\,f_m$ ($3\cdot10^{5} > 10^{5}$) sont vérifiées.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 4 <span class="font-normal text-white/80 text-sm">(5,5 points)</span></div>
**Partie 1 — Chute dans le champ de pesanteur.** **1.** Un corps est en **chute libre** s'il n'est soumis qu'à son poids.

**2.** Équation différentielle : projection de $\vec{P} = m\,\vec{a}_G$ sur $(O,\vec{k})$ : $\dfrac{dV_z}{dt} = -g$.

**3.** Équation horaire : $z = -\dfrac{1}{2}g\,t^2 + V_0\,t + h$.

**4.** Pente $a_z = \dfrac{\Delta V_z}{\Delta t} = \dfrac{0-10}{1-0} = -10~\mathrm{m\cdot s^{-2}}$ et $V_0 = 10~\mathrm{m\cdot s^{-1}}$ : $v_z = -10\,t + 10$.

**5.** Pour $V_B = 3~\mathrm{m\cdot s^{-1}}$ : $t_B = 0{,}7~\mathrm{s}$ et $D = z_B = -\dfrac{1}{2}\times10\times0{,}7^2 + 10\times0{,}7 + 1{,}2 = 5{,}75~\mathrm{m}$.

**6.** Avec $V_0' = 8~\mathrm{m\cdot s^{-1}}$ : la vitesse s'annule à $t_1 = \dfrac{V_0'}{10} = 0{,}8~\mathrm{s}$, d'où $d = -\dfrac{1}{2}\times10\times0{,}8^2 + 10\times0{,}8 + 1{,}2 = 4{,}4~\mathrm{m}$. Comme $d < D$, la balle **n'atteint pas** le point B.

**Partie 2 — Pendule de torsion.** **1.** À $t=0$, $E_{pt}$ est maximale : $E_{pt\,max} = 0{,}05~\mathrm{J}$ ; constante de torsion : $C = \dfrac{2E_{pt\,max}}{\theta_m^2} = \dfrac{2\times0{,}05}{0{,}5^2} = 0{,}4~\mathrm{N\cdot m\cdot rad^{-1}}$.

**2.** À $t=0$, $E_{C0}=0$ et $E_{pt0}=E_{pt\,max}$ donc $E_m = E_{pt} + E_C = 0{,}05~\mathrm{J}$ (constante).

**3.** À $t_1 = 0{,}3~\mathrm{s}$, $E_{pt1} = 0{,}025~\mathrm{J}$ d'où $E_{C1} = E_m - E_{pt1} = 0{,}05 - 0{,}025 = 0{,}025~\mathrm{J}$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 1 <span class="font-normal text-white/80 text-sm">(7 points)</span></div>
**Partie 1 — Dosage.** **1.** Éléments numérotés : ① pH-mètre ; ② burette ; ③ solution $S_a$ d'acide méthanoïque (solution titrée, dans le bécher) ; ④ solution $S_b$ d'hydroxyde de sodium (solution titrante).

**2.** Équation du dosage : $AH_{(aq)} + HO^-_{(aq)} \longrightarrow A^-_{(aq)} + H_2O_{(l)}$.

**3.** Volume à l'équivalence : $V_{bE} = 15~\mathrm{mL}$.

**4.** Concentration : $C_a = \dfrac{C_b\,V_{bE}}{V_a} = 10^{-1}~\mathrm{mol\cdot L^{-1}}$.

**Partie 1 — II. Étude de $S_a$.** **1.** Réaction avec l'eau : $AH_{(aq)} + H_2O_{(l)} \longrightarrow A^-_{(aq)} + H_3O^+_{(aq)}$.

**2.1.** $\dfrac{[A^-_{(aq)}]}{[AH_{(aq)}]} = \dfrac{10^{-pH}}{C_a - 10^{-pH}} = \dfrac{10^{-2{,}38}}{10^{-1} - 10^{-2{,}38}} = 4{,}35\cdot10^{-2}$.

**2.2.** $\dfrac{[A^-_{(aq)}]}{[AH_{(aq)}]} < 1$ donc l'espèce prédominante dans $S_a$ est l'acide $AH$.

**3.** $pK_A = pH - \log\dfrac{[A^-_{(aq)}]}{[AH_{(aq)}]} = 2{,}38 - \log(0{,}0435) \Rightarrow pK_A = 3{,}74$.

**Partie 1 — III. Influence de la dilution.** **1.** $\tau = \dfrac{x_f}{x_{max}} = \dfrac{10^{-pH}}{C}$.

**2.** Tableau complété :

| Solution | $S_1$ | $S_2$ |
|---|---|---|
| $pH$ | $2{,}8$ | $3{,}6$ |
| $\tau$ | $10\%$ | $45\%$ |
| $C~(\mathrm{mol\cdot L^{-1}})$ | $1{,}58\cdot10^{-2}$ | $5{,}58\cdot10^{-4}$ |

**3.** Comme $C_1 > C_2$ et $\tau_2 > \tau_1$ : plus la dilution augmente, plus le taux d'avancement final $\tau$ augmente.

**Partie 2 — Pile nickel-argent.** **1.** L'oxydation (perte d'électrons) se produit à l'**anode**, pôle $(-)$ : c'est l'électrode de **nickel** $Ni$.

**2.** Équation bilan : $2Ag^+_{(aq)} + Ni_{(s)} \longrightarrow Ni^{2+}_{(aq)} + 2Ag_{(s)}$.

**3.** Durée de fonctionnement : $\Delta t_{max} = \dfrac{2\,m\,F}{I\,M(Ni)} = 32166{,}67~\mathrm{s} \Rightarrow \Delta t_{max} = 8{,}935~\mathrm{h}$.

**4.** Concentration finale : $[Ni^{2+}] = C_1 + \dfrac{m}{M(Ni)\,V} \Rightarrow [Ni^{2+}] = 0{,}217~\mathrm{mol\cdot L^{-1}}$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 4 <span class="font-normal text-white/80 text-sm">(5,5 points)</span></div>
**I. Dipôle RC.** **1.** $u_C(0) = 0$ et $i(0) = 50~\mathrm{mA}$, d'où $R_1 = \dfrac{E}{i(0)} = \dfrac{6}{50\cdot10^{-3}} \Rightarrow R_1 = 120~\Omega$.

**2.** Par dérivation de $u_C + R_1 i = E$ avec $i = C\,\dfrac{du_C}{dt}$ : $i + R_1 C\,\dfrac{di}{dt} = 0$.

**3.** En reportant $i = I_0\,e^{-t/\tau}$ : $\tau = R_1 C$.

**4.** Graphiquement $\tau = 12~\mathrm{ms}$, d'où $C = \dfrac{\tau}{R_1} = \dfrac{12\cdot10^{-3}}{120} = 10^{-4}~\mathrm{F} \Rightarrow C = 100~\mathrm{\mu F}$.

**II. Dipôle RL.** **2.** $\dfrac{di}{dt} + \dfrac{1}{\tau}\,i = \dfrac{E}{L}$ avec $\tau = \dfrac{L}{R_2 + r}$.

**3.** En régime permanent $\dfrac{di}{dt} = 0$ : $I_P = \dfrac{E}{R_2 + r}$.

**4.** Graphiquement $I_P = 60~\mathrm{mA}$, d'où $r = \dfrac{E}{I_P} - R_2 = \dfrac{6}{60\cdot10^{-3}} - 95 \Rightarrow r = 5~\Omega$.

**5.** Graphiquement $\tau = 5{,}1~\mathrm{ms}$ : $L = \tau\,(R_2 + r) = 5{,}1\cdot10^{-3}\times100 \Rightarrow L = 0{,}51~\mathrm{H}$.

**III. Oscillations RLC.** **1.** Plus la résistance totale est grande, plus l'amortissement est fort : la courbe $(a)$ correspond à $R_3 = 10~\Omega$ et la courbe $(b)$ à $R_4 = 100~\Omega$.

**2.** Pseudopériode : $T = 45~\mathrm{ms}$ ; période propre $T_0 = 2\pi\sqrt{L\,C} = 4{,}49\cdot10^{-2}~\mathrm{s} \approx 4{,}5\cdot10^{-2}~\mathrm{s}$, donc $T \approx T_0$.

**3.** $E_{th} = E_T(t_1) - E_T(t_2) = 1{,}80 - 1{,}26 \Rightarrow E_{th} = 0{,}54~\mathrm{mJ}$.

<div class="my-5 rounded-lg px-4 py-2.5 text-white font-bold" style="background:#1F4E79">Exercice 5 <span class="font-normal text-white/80 text-sm">(3 points)</span></div>
**1.** $\vec{P} = m\,\vec{a_G} \Rightarrow \vec{a_G} = \vec{g}$. Projections : $\dfrac{dv_x}{dt} = 0$ ; $\dfrac{dv_y}{dt} = -g$.

**2.** Avec $v_{0x} = V_0\cos\alpha$ et $v_{0y} = V_0\sin\alpha$ : $v_x(t) = V_0\cos\alpha$ ; $v_y(t) = -g\,t + V_0\sin\alpha$.

**3.1.** Pente de $C_2$ : $K = \dfrac{0 - 6}{0{,}6 - 0} = -10~\mathrm{m\cdot s^{-2}}$, d'où $g = 10~\mathrm{m\cdot s^{-2}}$.

**3.2.** $\tan\alpha = \dfrac{v_{0y}}{v_{0x}} = \dfrac{6}{69{,}7} \Rightarrow \alpha = 4{,}92^\circ$.

**3.3.** $V_0 = \sqrt{v_{0x}^2 + v_{0y}^2} = \sqrt{69{,}7^2 + 6^2} \Rightarrow V_0 \approx 69{,}96~\mathrm{m\cdot s^{-1}}$.

**4.** $t_E = \dfrac{D}{v_{0x}}$ ; $v_{Ey} = -g\,t_E + v_{0y} = -10\times\dfrac{80}{69{,}7} + 6 = -5{,}48~\mathrm{m\cdot s^{-1}}$, et $v_{Ex} = 69{,}7~\mathrm{m\cdot s^{-1}}$, d'où $V_E = \sqrt{v_{Ex}^2 + v_{Ey}^2} = \sqrt{69{,}7^2 + (-5{,}48)^2} \Rightarrow V_E = 69{,}92~\mathrm{m\cdot s^{-1}}$.

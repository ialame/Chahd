### Problème 1 : De l'ADN à la protéine
\begin{enonce}
On étudie un fragment de gène intervenant dans la synthèse d'une protéine. La séquence du **brin transcrit** (brin modèle) de l'$\text{ADN}$ est :
\[
\text{3'} - \text{T} \text{A} \text{C} - \text{C} \text{G} \text{A} - \text{A} \text{A} \text{A} - \text{G} \text{G} \text{T} - \text{A} \text{T} \text{T} - \text{5'}
\]
On donne le code génétique partiel ($\text{ARNm}$ lu dans le sens $5' \rightarrow 3'$) :
AUG = Méthionine (Met) ; GCU = Alanine (Ala) ; UUU = Phénylalanine (Phe) ; CCA = Proline (Pro) ; UAA = STOP.
\begin{enumerate}
    \item Rappeler dans quel compartiment cellulaire se déroule la transcription et nommer l'enzyme responsable.
    \item Déterminer la séquence de l'$\text{ARNm}$ transcrit, en précisant son orientation.
    \item Découper l'$\text{ARNm}$ en codons et déterminer la séquence des acides aminés de la protéine.
    \item Indiquer le rôle du codon AUG et celui du codon UAA.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item La transcription se déroule dans le **noyau** de la cellule. L'enzyme responsable est l'**ARN polymérase**, qui parcourt le brin transcrit et assemble les ribonucléotides complémentaires.
    \item L'$\text{ARNm}$ est complémentaire du brin transcrit (A↔U, T↔A, C↔G, G↔C) et antiparallèle. Le brin transcrit étant orienté $3' \rightarrow 5'$, l'$\text{ARNm}$ s'écrit dans le sens $5' \rightarrow 3'$ :
    \[
    \text{5'} - \text{A} \text{U} \text{G} - \text{G} \text{C} \text{U} - \text{U} \text{U} \text{U} - \text{C} \text{C} \text{A} - \text{U} \text{A} \text{A} - \text{3'}
    \]
    \item La traduction commence au codon initiateur AUG :
    \begin{itemize}
        \item AUG $\rightarrow$ Méthionine (Met) ;
        \item GCU $\rightarrow$ Alanine (Ala) ;
        \item UUU $\rightarrow$ Phénylalanine (Phe) ;
        \item CCA $\rightarrow$ Proline (Pro) ;
        \item UAA $\rightarrow$ STOP (arrêt de la traduction).
    \end{itemize}
    La protéine obtenue est : **Met — Ala — Phe — Pro**.
    \item Le codon **AUG** est le **codon initiateur** (codon « start ») : il marque le début de la traduction et code la méthionine. Le codon **UAA** est un **codon stop** : il ne code aucun acide aminé et provoque l'arrêt de la synthèse et la libération de la protéine.
\end{enumerate}

### Problème 2 : Une mutation et ses conséquences
\begin{enonce}
On compare un gène **normal** et le même gène ayant subi une mutation. On considère uniquement le brin **non transcrit** (brin codant), dont la séquence est identique à celle de l'$\text{ARNm}$ avec T à la place de U.

\textbf{Allèle normal} (brin non transcrit) :
\[
\text{5'} - \text{A} \text{T} \text{G} - \text{A} \text{A} \text{A} - \text{G} \text{C} \text{T} - \text{T} \text{G} \text{A} - \text{3'}
\]

\textbf{Allèle muté} (brin non transcrit) :
\[
\text{5'} - \text{A} \text{T} \text{G} - \text{A} \text{A} \text{A} - \text{G} \text{A} \text{T} - \text{T} \text{G} \text{A} - \text{3'}
\]

On donne le code génétique partiel : AUG = Méthionine (Met) ; AAA = Lysine (Lys) ; GCU = Alanine (Ala) ; GAU = Aspartate (Asp) ; UGA = STOP.
\begin{enumerate}
    \item Écrire la séquence de l'$\text{ARNm}$ correspondant à l'allèle normal, puis la séquence des acides aminés.
    \item Faire de même pour l'allèle muté.
    \item Identifier précisément le changement de nucléotide et nommer le type de mutation.
    \item Décrire la conséquence de cette mutation sur la protéine. Cette mutation modifie-t-elle le cadre de lecture ?
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Le brin non transcrit a la même séquence que l'$\text{ARNm}$ (T remplacé par U). Pour l'allèle normal :
    \[
    \text{5'} - \text{A} \text{U} \text{G} - \text{A} \text{A} \text{A} - \text{G} \text{C} \text{U} - \text{U} \text{G} \text{A} - \text{3'}
    \]
    Traduction : AUG (Met) — AAA (Lys) — GCU (Ala) — UGA (STOP). Protéine normale : **Met — Lys — Ala**.
    \item Pour l'allèle muté :
    \[
    \text{5'} - \text{A} \text{U} \text{G} - \text{A} \text{A} \text{A} - \text{G} \text{A} \text{U} - \text{U} \text{G} \text{A} - \text{3'}
    \]
    Traduction : AUG (Met) — AAA (Lys) — GAU (Asp) — UGA (STOP). Protéine mutée : **Met — Lys — Asp**.
    \item Dans le troisième codon, le nucléotide **C a été remplacé par A** (GCU $\rightarrow$ GAU) : un seul nucléotide est remplacé par un autre, il s'agit d'une **mutation ponctuelle par substitution**.
    \item La substitution fait que le 3\textsuperscript{e} acide aminé est l'**aspartate (Asp)** au lieu de l'**alanine (Ala)** : **un seul acide aminé est modifié**, le reste de la protéine est inchangé. Comme le nombre de nucléotides n'est pas modifié, le **cadre de lecture est conservé** (contrairement à une addition ou une délétion qui le décaleraient).
\end{enumerate}

### Problème 3 : Substitution, délétion et addition comparées
\begin{enonce}
On part d'un même $\text{ARNm}$ de référence :
\[
\text{5'} - \text{A} \text{U} \text{G} - \text{C} \text{C} \text{U} - \text{A} \text{C} \text{U} - \text{G} \text{G} \text{A} - \text{3'}
\]
Trois mutations indépendantes sont étudiées :
\begin{itemize}
    \item \textbf{Mutation A} : le 5\textsuperscript{e} nucléotide (C du codon CCU) est remplacé par un A.
    \item \textbf{Mutation B} : le 4\textsuperscript{e} nucléotide (premier C du codon CCU) est supprimé.
    \item \textbf{Mutation C} : un nucléotide G est ajouté juste après le codon AUG.
\end{itemize}
On donne le code génétique partiel : AUG = Méthionine (Met) ; CCU = Proline (Pro) ; CAU = Histidine (His) ; ACU = Thréonine (Thr) ; GGA = Glycine (Gly) ; CUA = Leucine (Leu) ; CUG = Leucine (Leu) ; GCC = Alanine (Ala) ; UAC = Tyrosine (Tyr) ; UGG = Tryptophane (Trp) ; A\ldots (codon incomplet).
\begin{enumerate}
    \item Donner la séquence des acides aminés de l'$\text{ARNm}$ de référence.
    \item Pour la mutation A, écrire le nouvel $\text{ARNm}$, la nouvelle séquence d'acides aminés et nommer le type de mutation.
    \item Pour la mutation B, faire de même et expliquer pourquoi la protéine est fortement modifiée.
    \item Comparer les conséquences des trois mutations sur le cadre de lecture.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Découpage en codons : AUG — CCU — ACU — GGA. Traduction : Met — Pro — Thr — Gly. Protéine de référence : **Met — Pro — Thr — Gly**.
    \item Mutation A (substitution C $\rightarrow$ A en position 5) : le codon CCU devient CAU.
    \[
    \text{5'} - \text{A} \text{U} \text{G} - \text{C} \text{A} \text{U} - \text{A} \text{C} \text{U} - \text{G} \text{G} \text{A} - \text{3'}
    \]
    Traduction : Met — His — Thr — Gly. Un **seul acide aminé change** (Pro $\rightarrow$ His). Il s'agit d'une **substitution** ; le cadre de lecture est conservé.
    \item Mutation B (délétion du 4\textsuperscript{e} nucléotide) : on retire un C. La séquence devient :
    \[
    \text{5'} - \text{A} \text{U} \text{G} - \text{C} \text{U} \text{A} - \text{C} \text{U} \text{G} - \text{G} \text{A} \ldots - \text{3'}
    \]
    Nouveau découpage : AUG — CUA — CUG — GA… Traduction : Met — Leu — Leu — … La perte d'un nucléotide **décale le cadre de lecture** d'un cran vers la gauche : tous les codons situés en aval sont modifiés, donc la séquence d'acides aminés est **profondément changée** et la protéine est en général **non fonctionnelle**.
    \item Comparaison :
    \begin{itemize}
        \item Mutation A (**substitution**) : un nucléotide est remplacé, le nombre total de nucléotides est inchangé $\rightarrow$ le cadre de lecture est **conservé**, un seul acide aminé est touché.
        \item Mutation B (**délétion**) : un nucléotide est perdu $\rightarrow$ **décalage du cadre de lecture**, tous les acides aminés en aval sont modifiés.
        \item Mutation C (**addition**) : un nucléotide est ajouté $\rightarrow$ **décalage du cadre de lecture** également, avec des conséquences aussi importantes que la délétion.
    \end{itemize}
    Les mutations par addition et délétion sont donc, en général, **beaucoup plus graves** qu'une simple substitution.
\end{enumerate}

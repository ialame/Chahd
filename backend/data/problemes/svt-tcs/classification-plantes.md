### Problème 1 : Identifier des plantes avec une clé de détermination
\begin{enonce}
Lors d'une sortie sur le terrain, un élève récolte cinq végétaux et relève leurs caractères dans le tableau suivant :

| Plante | Appareil végétatif | Vaisseaux | Reproduction | Fruit |
|--------|--------------------|-----------|--------------|-------|
| 1 | thalle non différencié | non | spores | non |
| 2 | racines, tige, feuilles | oui | graines | oui |
| 3 | rhizoïdes, petites feuilles | non | spores | non |
| 4 | racines, tige, frondes | oui | spores | non |
| 5 | racines, tige, feuilles | oui | graines nues | non |

Il dispose de la clé de détermination dichotomique ci-dessous.



\begin{enumerate}
    \item Identifier le grand groupe de chacune des cinq plantes en utilisant la clé.
    \item Indiquer un exemple concret (nom commun) possible pour chaque plante.
    \item Quelle est la seule plante non vasculaire mais terrestre ?
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item En suivant la clé pour chaque ligne :
\begin{itemize}
    \item **Plante 1** : appareil non différencié (thalle) → **thallophyte (algue)**.
    \item **Plante 2** : différencié, vaisseaux oui, graines oui, fruit oui → **angiosperme**.
    \item **Plante 3** : différencié partiel sans vaisseaux, spores, fixée par rhizoïdes → **bryophyte (mousse)**.
    \item **Plante 4** : différencié, vaisseaux oui, reproduction par spores (pas de graines) → **ptéridophyte (fougère)**.
    \item **Plante 5** : différencié, vaisseaux oui, graines **nues** (pas de fruit) → **gymnosperme**.
\end{itemize}
    \item Exemples possibles : plante 1 = **laitue de mer** (ou fucus) ; plante 2 = **rosier** (ou oranger, blé) ; plante 3 = **mousse polytric** ; plante 4 = **fougère aigle** ; plante 5 = **pin** (ou sapin, cèdre).
    \item La seule plante **non vasculaire mais terrestre** est la **plante 3**, une **mousse** (bryophyte) : elle vit sur le sol mais ne possède pas de vaisseaux conducteurs.
\end{enumerate}

### Problème 2 : Construire une classification emboîtée
\begin{enonce}
On étudie six végétaux : **spirogyre (algue), mousse, fougère, sapin, maïs, haricot.**

Trois caractères évolutifs sont retenus :
\begin{itemize}
    \item C1 : présence de **vaisseaux conducteurs** ;
    \item C2 : reproduction par **graines** ;
    \item C3 : présence de **fleurs et de fruits**.
\end{itemize}
\begin{enumerate}
    \item Dresser un tableau indiquant, pour chaque végétal, la présence (+) ou l'absence (−) de chacun des trois caractères.
    \item Représenter la **classification emboîtée** de ces végétaux sous forme de boîtes incluses, une boîte par caractère.
    \item Le maïs et le haricot partagent tous ces caractères : comment peut-on néanmoins les séparer en deux sous-groupes d'angiospermes ?
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Tableau des caractères :

| Végétal | C1 vaisseaux | C2 graines | C3 fleurs/fruits |
|---------|:---:|:---:|:---:|
| spirogyre | − | − | − |
| mousse | − | − | − |
| fougère | + | − | − |
| sapin | + | + | − |
| maïs | + | + | + |
| haricot | + | + | + |

    \item Classification emboîtée (de la boîte la plus large à la plus restreinte) :
\begin{itemize}
    \item Boîte **C1 « vaisseaux »** : fougère, sapin, maïs, haricot. (En dehors : spirogyre et mousse.)
    \item À l'intérieur, boîte **C2 « graines »** : sapin, maïs, haricot. (La fougère reste hors de cette boîte.)
    \item À l'intérieur, boîte **C3 « fleurs et fruits »** : maïs, haricot. (Le sapin, à graines nues, reste hors de cette boîte.)
\end{itemize}
Chaque caractère nouveau définit une boîte plus petite incluse dans la précédente : c'est l'apparition progressive des caractères au cours de l'évolution.
    \item Le maïs et le haricot sont tous deux des **angiospermes**, mais on les sépare selon le **nombre de cotylédons** de la graine : le **maïs** est une **monocotylédone** (un cotylédon, nervures parallèles) et le **haricot** une **dicotylédone** (deux cotylédons, nervures ramifiées).
\end{enumerate}

### Problème 3 : Construire une clé de détermination
\begin{enonce}
On veut bâtir une petite clé de détermination dichotomique permettant de distinguer quatre végétaux : une **algue**, une **mousse**, une **fougère** et un **pommier**.

On rappelle les caractères observables : appareil végétatif différencié ou non, présence de vaisseaux, présence de graines, présence de fruits.
\begin{enumerate}
    \item Choisir l'ordre des caractères à tester, du plus général au plus précis, et justifier ce choix.
    \item Rédiger la clé de détermination dichotomique correspondante (suite de choix entre deux propositions).
    \item Vérifier la clé en identifiant la **mousse**, puis le **pommier**.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item On teste les caractères **du plus général au plus précis** : d'abord l'appareil végétatif (différencié ou non, qui isole l'algue), puis les vaisseaux (qui isolent la mousse), puis les graines/fruits (qui isolent la fougère du pommier). Cet ordre suit l'apparition des caractères au cours de l'évolution, ce qui garantit qu'à chaque étape une seule catégorie est écartée.
    \item Clé de détermination :
\begin{itemize}
    \item **1.** Appareil végétatif **non différencié** (thalle) ............ **algue** ;
    \item Appareil végétatif **différencié** (racines, tige, feuilles) ............ aller en **2**.
    \item **2.** **Pas** de vaisseaux conducteurs ............ **mousse** ;
    \item **Présence** de vaisseaux conducteurs ............ aller en **3**.
    \item **3.** Reproduction par **spores**, pas de graines ............ **fougère** ;
    \item Reproduction par **graines** enfermées dans un **fruit** ............ **pommier**.
\end{itemize}
    \item Vérification :
\begin{itemize}
    \item **Mousse** : appareil différencié → 2 ; pas de vaisseaux → **mousse**. Correct.
    \item **Pommier** : appareil différencié → 2 ; vaisseaux présents → 3 ; graines dans un fruit (la pomme) → **pommier**. Correct.
\end{itemize}
\end{enumerate}

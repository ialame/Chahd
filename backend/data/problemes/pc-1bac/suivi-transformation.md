### Problème 1 : Le fer dans l'acide chlorhydrique
\begin{enonce}
On verse une masse $m = 2{,}8\ g$ de poudre de fer dans $V = 200\ mL$ d'une solution d'acide chlorhydrique de concentration $C = 0{,}40\ mol/L$. La transformation, totale, est modélisée par :
$$Fe_{(s)} + 2\,H^+_{(aq)} \longrightarrow Fe^{2+}_{(aq)} + H_{2(g)}$$
\emph{Données} : $M(Fe) = 56\ g/mol$ ; $V_m = 24\ L/mol$. On suppose le volume de la solution constant.
\begin{enumerate}
    \item Calculer les quantités de matière initiales de fer et d'ions $H^+$.
    \item Dresser le tableau d'avancement de la réaction.
    \item Déterminer le réactif limitant et l'avancement maximal $x_{max}$.
    \item Donner la composition complète du système à l'état final.
    \item Calculer le volume de dihydrogène dégagé.
    \item Déterminer la concentration des ions $Fe^{2+}$ dans la solution finale.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item $n_0(Fe) = \dfrac{m}{M} = \dfrac{2{,}8}{56} = 5{,}0\times10^{-2}\ mol$ ; $\quad n_0(H^+) = C\,V = 0{,}40\times0{,}200 = 8{,}0\times10^{-2}\ mol$.
    \item Tableau d'avancement (quantités en $mol$) :

| Équation | $Fe$ | $+\ 2\,H^+$ | $\rightarrow$ | $Fe^{2+}$ | $+\ H_2$ |
|---|---|---|---|---|---|
| État initial ($x=0$) | $5{,}0\times10^{-2}$ | $8{,}0\times10^{-2}$ | | $0$ | $0$ |
| État interm. ($x$) | $5{,}0\times10^{-2} - x$ | $8{,}0\times10^{-2} - 2x$ | | $x$ | $x$ |
| État final ($x_{max}$) | $5{,}0\times10^{-2} - x_{max}$ | $8{,}0\times10^{-2} - 2x_{max}$ | | $x_{max}$ | $x_{max}$ |

    \item $x_{Fe} = \dfrac{5{,}0\times10^{-2}}{1} = 5{,}0\times10^{-2}\ mol$ ; $x_{H^+} = \dfrac{8{,}0\times10^{-2}}{2} = 4{,}0\times10^{-2}\ mol$. Le minimum est $4{,}0\times10^{-2}\ mol$ : $x_{max} = 4{,}0\times10^{-2}\ mol$ et les **ions $H^+$** constituent le réactif limitant.
    \item À l'état final :
    \begin{itemize}
        \item $n(Fe) = 5{,}0\times10^{-2} - 4{,}0\times10^{-2} = 1{,}0\times10^{-2}\ mol$ (il reste du fer solide) ;
        \item $n(H^+) = 8{,}0\times10^{-2} - 2\times4{,}0\times10^{-2} = 0\ mol$ ;
        \item $n(Fe^{2+}) = x_{max} = 4{,}0\times10^{-2}\ mol$ ;
        \item $n(H_2) = x_{max} = 4{,}0\times10^{-2}\ mol$.
    \end{itemize}
    \item $V(H_2) = n(H_2)\times V_m = 4{,}0\times10^{-2}\times24 = 0{,}96\ L$.
    \item $[Fe^{2+}] = \dfrac{n(Fe^{2+})}{V} = \dfrac{4{,}0\times10^{-2}}{0{,}200} = 0{,}20\ mol/L$.
\end{enumerate}

### Problème 2 : Combustion complète du butane
\begin{enonce}
Le butane $C_4H_{10}$ brûle dans le dioxygène selon :
$$2\,C_4H_{10} + 13\,O_2 \longrightarrow 8\,CO_2 + 10\,H_2O$$
On dispose de $n_0(C_4H_{10}) = 0{,}10\ mol$ de butane et l'on souhaite réaliser une combustion en mélange stœchiométrique.
\emph{Données} : $V_m = 24\ L/mol$ ; $M(H_2O) = 18\ g/mol$.
\begin{enumerate}
    \item Quelle quantité de dioxygène faut-il employer pour que le mélange soit stœchiométrique ?
    \item Déterminer l'avancement maximal $x_{max}$.
    \item Calculer le volume de dioxyde de carbone formé.
    \item Calculer la masse d'eau produite.
    \item Justifier qu'à l'état final il ne reste ni butane ni dioxygène.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Condition stœchiométrique : $\dfrac{n_0(C_4H_{10})}{2} = \dfrac{n_0(O_2)}{13}$, d'où :
$$n_0(O_2) = \frac{13}{2}\times n_0(C_4H_{10}) = 6{,}5\times0{,}10 = 0{,}65\ mol.$$
    \item Le mélange étant stœchiométrique, on peut prendre n'importe quel réactif :
$$x_{max} = \frac{n_0(C_4H_{10})}{2} = \frac{0{,}10}{2} = 0{,}050\ mol \quad\left(=\frac{n_0(O_2)}{13} = \frac{0{,}65}{13} = 0{,}050\ mol\right).$$
    \item $n(CO_2) = 8\,x_{max} = 8\times0{,}050 = 0{,}40\ mol$, donc :
$$V(CO_2) = 0{,}40\times24 = 9{,}6\ L.$$
    \item $n(H_2O) = 10\,x_{max} = 10\times0{,}050 = 0{,}50\ mol$, donc :
$$m(H_2O) = n\times M = 0{,}50\times18 = 9{,}0\ g.$$
    \item Dans un mélange stœchiométrique, tous les réactifs sont limitants et disparaissent simultanément à $x_{max}$ : $n(C_4H_{10}) = 0{,}10 - 2\times0{,}050 = 0$ et $n(O_2) = 0{,}65 - 13\times0{,}050 = 0$.
\end{enumerate}

### Problème 3 : Suivi temporel par mesure du volume de gaz
\begin{enonce}
On fait réagir une masse $m = 1{,}0\ g$ de carbonate de calcium $CaCO_3$ avec $V = 100\ mL$ d'acide chlorhydrique de concentration $C = 0{,}50\ mol/L$. La réaction libère du dioxyde de carbone :
$$CaCO_{3(s)} + 2\,H^+_{(aq)} \longrightarrow Ca^{2+}_{(aq)} + H_2O_{(l)} + CO_{2(g)}$$
On mesure le volume $V(CO_2)$ de gaz dégagé au cours du temps :

| $t$ (s) | $0$ | $10$ | $20$ | $40$ | $60$ | $80$ | $100$ |
|---|---|---|---|---|---|---|---|
| $V(CO_2)$ (mL) | $0$ | $95$ | $150$ | $210$ | $232$ | $240$ | $240$ |

\emph{Données} : $M(CaCO_3) = 100\ g/mol$ ; $V_m = 24\ L/mol$ (soit $24\,000\ mL/mol$).
\begin{enumerate}
    \item Calculer les quantités de matière initiales de $CaCO_3$ et d'ions $H^+$.
    \item Déterminer le réactif limitant et l'avancement maximal $x_{max}$ théorique.
    \item En déduire le volume théorique de $CO_2$ dégagé. Comparer au palier expérimental.
    \item Exprimer l'avancement $x$ en fonction de $V(CO_2)$, puis déterminer graphiquement (ou par lecture du tableau) le temps de demi-réaction $t_{1/2}$.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item $n_0(CaCO_3) = \dfrac{m}{M} = \dfrac{1{,}0}{100} = 1{,}0\times10^{-2}\ mol$ ; $\quad n_0(H^+) = C\,V = 0{,}50\times0{,}100 = 5{,}0\times10^{-2}\ mol$.
    \item $x_{CaCO_3} = \dfrac{1{,}0\times10^{-2}}{1} = 1{,}0\times10^{-2}\ mol$ ; $x_{H^+} = \dfrac{5{,}0\times10^{-2}}{2} = 2{,}5\times10^{-2}\ mol$. Le minimum est $1{,}0\times10^{-2}\ mol$ : $x_{max} = 1{,}0\times10^{-2}\ mol$ et le **carbonate de calcium** est le réactif limitant (l'acide est en excès).
    \item $n(CO_2) = x_{max} = 1{,}0\times10^{-2}\ mol$, donc :
$$V(CO_2)_{th} = x_{max}\times V_m = 1{,}0\times10^{-2}\times24\,000 = 240\ mL.$$
Cette valeur coïncide avec le palier expérimental ($240\ mL$) : la réaction est bien totale.
    \item Comme $n(CO_2) = x$, on a $x = \dfrac{V(CO_2)}{V_m}$. La demi-réaction correspond à $x = \dfrac{x_{max}}{2} = 5{,}0\times10^{-3}\ mol$, soit $V(CO_2) = \dfrac{240}{2} = 120\ mL$. Le tableau montre que ce volume est atteint entre $t = 10\ s$ ($95\ mL$) et $t = 20\ s$ ($150\ mL$) : par lecture, $t_{1/2} \approx 14\ s$.
\end{enumerate}

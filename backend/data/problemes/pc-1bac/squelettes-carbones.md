### Problème 1 : Identifier un alcane à partir de sa masse molaire
\begin{enonce}
Un hydrocarbure gazeux $A$ est un alcane. Sa masse molaire vaut $M = 58\ \text{g}\cdot\text{mol}^{-1}$.

\emph{Données :} masses molaires atomiques $M(\text{C}) = 12\ \text{g}\cdot\text{mol}^{-1}$ et $M(\text{H}) = 1\ \text{g}\cdot\text{mol}^{-1}$.
\begin{enumerate}
    \item Exprimer la masse molaire d'un alcane $\text{C}_n\text{H}_{2n+2}$ en fonction de $n$.
    \item En déduire le nombre $n$ d'atomes de carbone, puis la formule brute de $A$.
    \item Écrire les formules semi-développées de tous les isomères de $A$ et les nommer.
    \item Quel groupe alkyle obtient-on en retirant un atome d'hydrogène terminal à l'isomère linéaire ? Donner son nom et sa formule.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item La masse molaire d'un alcane est $M = 12\,n + 1\times(2n+2) = 14\,n + 2$ (en $\text{g}\cdot\text{mol}^{-1}$).
    \item On résout $14\,n + 2 = 58$, soit $14\,n = 56$ et $n = 4$. La formule brute de $A$ est donc $\text{C}_4\text{H}_{10}$.
    \item $\text{C}_4\text{H}_{10}$ possède deux isomères de constitution :
\begin{itemize}
    \item le \textbf{butane} : $\text{CH}_3-\text{CH}_2-\text{CH}_2-\text{CH}_3$ (chaîne linéaire) ;
    \item le \textbf{2-méthylpropane} : $\text{CH}_3-\text{CH}(\text{CH}_3)-\text{CH}_3$ (chaîne ramifiée).
\end{itemize}
    \item En retirant un atome d'hydrogène terminal au butane, on obtient le groupe \textbf{butyle} $-\text{C}_4\text{H}_9$.
\end{enumerate}

### Problème 2 : Nomenclature et chaîne principale
\begin{enonce}
On étudie plusieurs alcanes ramifiés.
\begin{enumerate}
    \item Identifier la chaîne principale et nommer la molécule $A$ : $\text{CH}_3-\text{CH}(\text{CH}_3)-\text{CH}(\text{CH}_3)-\text{CH}_2-\text{CH}_3$. Donner sa formule brute.
    \item Nommer la molécule $B$ : $\text{CH}_3-\text{C}(\text{CH}_3)_2-\text{CH}_2-\text{CH}_3$.
    \item Écrire la formule semi-développée du \textbf{3-éthyl-2-méthylpentane}. Justifier l'ordre dans lequel les ramifications apparaissent dans le nom.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item La chaîne la plus longue compte 5 carbones (pent-). Elle porte deux groupes méthyles. En numérotant à partir de l'extrémité gauche, ils occupent les positions 2 et 3 (indices les plus petits). La molécule $A$ est le \textbf{2,3-diméthylpentane}, de formule brute $\text{C}_7\text{H}_{16}$.
    \item La chaîne principale compte 4 carbones (but-). Le deuxième carbone porte deux groupes méthyles, en positions 2 et 2. La molécule $B$ est le \textbf{2,2-diméthylbutane} ($\text{C}_6\text{H}_{14}$).
    \item La chaîne principale est le pentane (5 carbones) ; le carbone 2 porte un méthyle et le carbone 3 un éthyle. La formule semi-développée est :
\[
\text{CH}_3-\text{CH}(\text{CH}_3)-\text{CH}(\text{C}_2\text{H}_5)-\text{CH}_2-\text{CH}_3
\]
Dans le nom, les ramifications sont citées par \textbf{ordre alphabétique} : « éthyl » avant « méthyl », d'où l'écriture 3-éthyl-2-méthylpentane.
\end{enumerate}

### Problème 3 : Les cinq isomères de $\text{C}_6\text{H}_{14}$
\begin{enonce}
On s'intéresse aux alcanes de formule brute $\text{C}_6\text{H}_{14}$.
\begin{enumerate}
    \item Vérifier que $\text{C}_6\text{H}_{14}$ correspond bien à un alcane à 6 atomes de carbone.
    \item Écrire les formules semi-développées des cinq isomères de constitution et les nommer.
    \item Parmi ces isomères, indiquer celui dont la chaîne est linéaire et celui qui possède un atome de carbone lié à quatre autres atomes de carbone.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Pour $n = 6$, la formule générale $\text{C}_n\text{H}_{2n+2}$ donne $2\times 6 + 2 = 14$ atomes d'hydrogène : $\text{C}_6\text{H}_{14}$ est bien l'alcane à 6 carbones.
    \item Les cinq isomères sont :
\begin{itemize}
    \item l'\textbf{hexane} : $\text{CH}_3-\text{CH}_2-\text{CH}_2-\text{CH}_2-\text{CH}_2-\text{CH}_3$ ;
    \item le \textbf{2-méthylpentane} : $\text{CH}_3-\text{CH}(\text{CH}_3)-\text{CH}_2-\text{CH}_2-\text{CH}_3$ ;
    \item le \textbf{3-méthylpentane} : $\text{CH}_3-\text{CH}_2-\text{CH}(\text{CH}_3)-\text{CH}_2-\text{CH}_3$ ;
    \item le \textbf{2,2-diméthylbutane} : $\text{CH}_3-\text{C}(\text{CH}_3)_2-\text{CH}_2-\text{CH}_3$ ;
    \item le \textbf{2,3-diméthylbutane} : $\text{CH}_3-\text{CH}(\text{CH}_3)-\text{CH}(\text{CH}_3)-\text{CH}_3$.
\end{itemize}
    \item L'\textbf{hexane} est le seul à chaîne linéaire. Le \textbf{2,2-diméthylbutane} possède un carbone (le carbone 2) lié à quatre autres atomes de carbone.
\end{enumerate}

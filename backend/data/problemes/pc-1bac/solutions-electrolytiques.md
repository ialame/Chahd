### Problème 1 : Sérum physiologique
\begin{enonce}
Le sérum physiologique est une solution aqueuse de chlorure de sodium $\text{NaCl}$. Une ampoule de volume $V = 20\ \text{mL}$ contient une masse $m = 0{,}18\ \text{g}$ de $\text{NaCl}$.
Donnée : $M(\text{NaCl}) = 58{,}5\ \text{g}\cdot\text{mol}^{-1}$.
\begin{enumerate}
    \item Écrire l'équation de dissolution de $\text{NaCl}$ dans l'eau.
    \item Calculer la quantité de matière $n$ de $\text{NaCl}$ dissous.
    \item En déduire la concentration molaire apportée $C$.
    \item Déterminer les concentrations effectives $[\text{Na}^+]$ et $[\text{Cl}^-]$, puis vérifier l'électroneutralité.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item L'équation de dissolution est :
$$\text{NaCl}_{(s)} \longrightarrow \text{Na}^+_{(aq)} + \text{Cl}^-_{(aq)}$$
    \item La quantité de matière vaut :
$$n = \dfrac{m}{M} = \dfrac{0{,}18}{58{,}5} = 3{,}08 \times 10^{-3}\ \text{mol}$$
    \item Avec $V = 20\ \text{mL} = 0{,}020\ \text{L}$ :
$$C = \dfrac{n}{V} = \dfrac{3{,}08 \times 10^{-3}}{0{,}020} = 0{,}154\ \text{mol}\cdot\text{L}^{-1} \approx 0{,}15\ \text{mol}\cdot\text{L}^{-1}$$
    \item Les coefficients stœchiométriques valant 1 :
$$[\text{Na}^+] = [\text{Cl}^-] = C = 0{,}15\ \text{mol}\cdot\text{L}^{-1}$$
L'électroneutralité $[\text{Na}^+] = [\text{Cl}^-]$ est bien vérifiée : la solution est neutre.
\end{enumerate}

### Problème 2 : Préparation par dissolution puis dilution
\begin{enonce}
On souhaite étudier une solution de chlorure de magnésium $\text{MgCl}_2$.
\textbf{Partie A — Solution mère.} On dissout une masse $m$ de $\text{MgCl}_2$ dans l'eau pour obtenir $V_0 = 250\ \text{mL}$ de solution mère de concentration apportée $C_0 = 0{,}20\ \text{mol}\cdot\text{L}^{-1}$.
Donnée : $M(\text{MgCl}_2) = 95\ \text{g}\cdot\text{mol}^{-1}$.
\begin{enumerate}
    \item Écrire l'équation de dissolution.
    \item Calculer la masse $m$ à peser.
    \item Déterminer $[\text{Mg}^{2+}]$ et $[\text{Cl}^-]$ dans la solution mère.
\end{enumerate}
\textbf{Partie B — Solution fille.} On prélève $V_1 = 25\ \text{mL}$ de la solution mère et on les complète à $V_2 = 100\ \text{mL}$.
\begin{enumerate}
    \setcounter{enumi}{3}
    \item Calculer la concentration apportée $C_2$ de la solution fille et son facteur de dilution.
    \item En déduire les nouvelles concentrations effectives $[\text{Mg}^{2+}]$ et $[\text{Cl}^-]$.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item $\text{MgCl}_{2\,(s)} \longrightarrow \text{Mg}^{2+}_{(aq)} + 2\,\text{Cl}^-_{(aq)}$
    \item La quantité nécessaire est $n = C_0 \times V_0 = 0{,}20 \times 0{,}250 = 0{,}050\ \text{mol}$, d'où :
$$m = n \times M = 0{,}050 \times 95 = 4{,}75\ \text{g}$$
    \item D'après les coefficients stœchiométriques :
$$[\text{Mg}^{2+}] = C_0 = 0{,}20\ \text{mol}\cdot\text{L}^{-1}, \qquad [\text{Cl}^-] = 2\,C_0 = 0{,}40\ \text{mol}\cdot\text{L}^{-1}$$
    \item La relation de dilution $C_0 V_1 = C_2 V_2$ donne :
$$C_2 = \dfrac{C_0\,V_1}{V_2} = \dfrac{0{,}20 \times 25}{100} = 0{,}050\ \text{mol}\cdot\text{L}^{-1}$$
Le facteur de dilution vaut $F = \dfrac{C_0}{C_2} = \dfrac{0{,}20}{0{,}050} = 4$ (ce que confirme $\dfrac{V_2}{V_1} = \dfrac{100}{25} = 4$).
    \item Dans la solution fille :
$$[\text{Mg}^{2+}] = C_2 = 0{,}050\ \text{mol}\cdot\text{L}^{-1}, \qquad [\text{Cl}^-] = 2\,C_2 = 0{,}10\ \text{mol}\cdot\text{L}^{-1}$$
Toutes les concentrations ont bien été divisées par 4, comme la concentration apportée.
\end{enumerate}

### Problème 3 : Mélange de deux solutions ioniques
\begin{enonce}
On mélange $V_1 = 100\ \text{mL}$ d'une solution de chlorure de sodium $\text{NaCl}$ de concentration $C_1 = 0{,}10\ \text{mol}\cdot\text{L}^{-1}$ avec $V_2 = 100\ \text{mL}$ d'une solution de chlorure de baryum $\text{BaCl}_2$ de concentration $C_2 = 0{,}050\ \text{mol}\cdot\text{L}^{-1}$. On suppose les volumes additifs et l'absence de réaction.
\begin{enumerate}
    \item Calculer les quantités de matière des ions $\text{Na}^+$, $\text{Ba}^{2+}$ et $\text{Cl}^-$ apportées par chaque solution.
    \item Quel est le volume total $V$ du mélange ?
    \item En déduire les concentrations effectives $[\text{Na}^+]$, $[\text{Ba}^{2+}]$ et $[\text{Cl}^-]$ dans le mélange.
    \item Vérifier l'électroneutralité de la solution finale.
\end{enumerate}
\end{enonce}

\textbf{Solution :}
\begin{enumerate}
    \item Les équations de dissolution sont $\text{NaCl}_{(s)} \longrightarrow \text{Na}^+_{(aq)} + \text{Cl}^-_{(aq)}$ et $\text{BaCl}_{2\,(s)} \longrightarrow \text{Ba}^{2+}_{(aq)} + 2\,\text{Cl}^-_{(aq)}$.
    \begin{itemize}
        \item Solution 1 : $n(\text{Na}^+) = C_1 V_1 = 0{,}10 \times 0{,}100 = 1{,}0 \times 10^{-2}\ \text{mol}$ et $n_1(\text{Cl}^-) = 1{,}0 \times 10^{-2}\ \text{mol}$.
        \item Solution 2 : $n(\text{Ba}^{2+}) = C_2 V_2 = 0{,}050 \times 0{,}100 = 5{,}0 \times 10^{-3}\ \text{mol}$ et $n_2(\text{Cl}^-) = 2 \times 5{,}0 \times 10^{-3} = 1{,}0 \times 10^{-2}\ \text{mol}$.
    \end{itemize}
    \item Les volumes étant additifs :
$$V = V_1 + V_2 = 100 + 100 = 200\ \text{mL} = 0{,}200\ \text{L}$$
    \item Chaque concentration effective est la quantité totale d'ion divisée par $V$. La quantité totale de chlorure vaut $n(\text{Cl}^-) = 1{,}0 \times 10^{-2} + 1{,}0 \times 10^{-2} = 2{,}0 \times 10^{-2}\ \text{mol}$ :
$$[\text{Na}^+] = \dfrac{1{,}0 \times 10^{-2}}{0{,}200} = 0{,}050\ \text{mol}\cdot\text{L}^{-1}$$
$$[\text{Ba}^{2+}] = \dfrac{5{,}0 \times 10^{-3}}{0{,}200} = 0{,}025\ \text{mol}\cdot\text{L}^{-1}$$
$$[\text{Cl}^-] = \dfrac{2{,}0 \times 10^{-2}}{0{,}200} = 0{,}10\ \text{mol}\cdot\text{L}^{-1}$$
    \item L'électroneutralité impose $[\text{Na}^+] + 2\,[\text{Ba}^{2+}] = [\text{Cl}^-]$ :
$$0{,}050 + 2 \times 0{,}025 = 0{,}10 = [\text{Cl}^-]\ \checkmark$$
La solution finale est bien électriquement neutre.
\end{enumerate}
